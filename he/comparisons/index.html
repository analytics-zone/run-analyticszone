שאלות נפוצות

האם אני יכול להשתמש ב-Run Analytics וב-Strava/TrainingPeaks?

כן - רצים רבים משתמשים בשניהם.השתמש ב-Run Analytics לניתוח ביצועים (CRS, rTSS, PMC) ו-Strava לשיתוף חברתי ורישום רישום ספורט רב. הם משלימים זה את זה היטב.

האם Run Analytics עובד עם שעוני Garmin?

לא.Run Analytics מסתנכרן באמצעות Apple Health, הדורש Apple Watch. אם אתה משתמש ב-Garmin, שקול במקום זאת TrainingPeaks או Final Surge.

מדוע Run Analytics זול בהרבה מ-TrainingPeaks?

Run Analytics הואריצה בלבד, לא ספורט רב. על ידי התמקדות בלעדית בריצה, אנחנו הימנע מהמורכבות ועלויות התשתית של תמיכת מדי כוח אופניים, דינמיקה של ריצה, מאמן פלטפורמות וכו' זה מאפשר לנו להציע PMC + rTSS בעלות נמוכה יותר ב-80%.

מה אם אני טריאתלט - האם עלי להשתמש ב-Run Analytics?

כנראה לא כאפליקציה הראשית שלך.טריאתלטים נהנים מפלטפורמות ריבוי ספורט כמו TrainingPeaks שעוקבים אחר אופניים, ריצה ורוץ ביחד. עם זאת, כמה טריאתלטים משתמשים ב-Run Analytics עבור ניתוחים ספציפיים לריצה (אזורי CRS) ו-TrainingPeaks לעומס האימון הכולל.

האם ל-Run Analytics יש שכבה חינמית?

Run Analytics מציעה אניסיון חינם ל-7 ימיםעם תכונות מלאות (בדיקת CRS, rTSS, PMC). לאחר ניסיון, זה 3.99 $ לחודש ללא התחייבות לטווח ארוך. אין רמה חופשית - אנו מאמינים שלספורטאים מגיע מלא ניתוח ללא נעילות תכונות שרירותיות.

מוכן לנסות את Run Analytics?

התנסה באזורי אימון מבוססי CRS, rTSS אוטומטי ומדדי PMC במחירים נוחים תוכנן במיוחד עבור רצים.
