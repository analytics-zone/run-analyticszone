О Run Analytics

Научно обоснованное отслеживание результатов бега, созданное бегунами для бегунов.

Наша миссия

Run Analyticsобеспечивает профессиональное отслеживание результатов каждому бегуну. Мы считаем, что расширенные показатели, такие как критическая скорость бега (CRS), оценка тренировочного стресса (TSS) и диаграммы управления производительностью, не должны быть привязаны к дорогим платформам или требовать сложного программного обеспечения для тренировок.

Наши принципы

  • Наука прежде всего:Все показатели основаны на рецензируемых исследованиях. Мы цитируем наши источники и показываем наши формулы.
  • Конфиденциальность по замыслу:100% локальная обработка данных. Никаких серверов, никаких учетных записей, никакого отслеживания. Вы владеете своими данными.
  • Независимость от платформы:Работает с любым устройством, совместимым с Apple Health. Никакой привязки к поставщику.
  • Прозрачность:Открытые формулы, четкие расчеты, честные ограничения. Никаких алгоритмов черного ящика.
  • Доступность:Расширенные показатели не должны требовать ученой степени в области спортивных наук. Мы ясно объясняем концепции.

Научный Фонд

Run Analytics основан на десятилетиях рецензируемых научных исследований в области спорта:

Критическая скорость работы (CRS)

На основе Wakayoshi и др. (1992-1993) исследования в Университете Осаки. CRS представляет собой теоретическую максимальную скорость бега, устойчивую без утомления, соответствующую порогу лактата.

Ключевые исследования:Wakayoshi K и др. «Определение и обоснованность критической скорости как показателя беговых качеств». Европейский журнал прикладной физиологии, 1992.

Оценка тренировочного стресса (TSS)

Адаптировано на основе методологии бега TSS доктора Эндрю Коггана. Количественно определяет тренировочную нагрузку путем объединения интенсивности (относительно CRS) и продолжительности.

Ключевые исследования:Когган А.Р., Аллен Х. «Тренировки и гонки с измерителем мощности». VeloPress, 2010. Адаптировано для работы Run Analytics с использованием CRS в качестве порога.

Схема управления производительностью (PMC)

Показатели хронической тренировочной нагрузки (CTL), острой тренировочной нагрузки (ATL) и баланса тренировочного стресса (TSB). Отслеживает физическую форму, усталость и форму с течением времени.

Реализация:42-дневная экспоненциально взвешенная скользящая средняя для CTL, 7-дневная для ATL. TSB = CTL - ATL.

Показатели эффективности бега и шага

Показатели эффективности бега, объединяющие время и количество шагов. Используется элитными бегунами и тренерами по всему миру для отслеживания технических усовершенствований.

Стандартные метрики:Эффективность бега = Время + Шаги. Более низкие баллы указывают на более высокую эффективность. Дополняется расстоянием на шаг (DPS) и частотой шагов (SR).

Разработка и обновления

Run Analytics активно развивается с регулярными обновлениями на основе отзывов пользователей и последних научных исследований в области спорта. Приложение построено на:

  • Swift и SwiftUI- Современная собственная разработка iOS.
  • Интеграция HealthKit- Бесшовная синхронизация Apple Health
  • Основные данные- Эффективное локальное хранилище данных
  • Быстрые графики- Красивая интерактивная визуализация данных
  • Никакой сторонней аналитики- Ваши данные об использовании остаются конфиденциальными
