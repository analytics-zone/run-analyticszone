Nipa Run Analytics

Ìgbékalẹ̀ ṣíṣe àyẹ̀wò ìsáré tí ìmọ̀ sáyẹ́nsì gbé, tí àwọn olóṣìṣe ìsáré ṣe fún àwọn olóṣìṣe ìsáré

Ète Wa

Run Analytics mú ìgbékalẹ̀ ṣíṣe àyẹ̀wò ìsáré tí ó ga tó aṣojú gbogbo olóṣìṣe ìsáré wá. A gbà gbọ́ pé àwọn mẹ́tríkì tó jìnnà síi bíi Critical Run Speed (CRS), Training Stress Score (TSS), àti Performance Management Charts kò yẹ kó wà lẹ́yìn àwọn ìrìn àjò owó tàbí kó nílò sọ́ftíwéà ìkọ́nilẹ́kọ̀ọ́ tó ṣòro.

Àwọn Ìlànà Wa

  • Ìmọ̀ Sáyẹ́nsì Kọ́kọ́: Gbogbo mẹ́tríkì dá lórí ìwádìí tí àwọn ẹlẹgbẹ́ ṣàgbéyẹ̀wò. A tọ́ka sí àwọn orísun wa tí a sì fihàn àwọn fọ́mù wa.
  • Ìkọ̀kọ̀ nípasẹ̀ Ìgbéjókòó: 100% ìṣeéṣe àkójọpọ̀ data àdúgbò. Kò sí ìkésẹ̀-bẹ̀rẹ̀, kò sí àkáǹtì, kò sí ìtọ́pàtọ́. Ìwọ ní ohun ìní data rẹ.
  • Ìlànà Àgbáyé: Ń ṣiṣẹ́ pẹ̀lú ẹ̀rọ tó bá Apple Health mu. Kò sí ìdóti ìtàjà.
  • Ìfihàn Gbangba: Àwọn fọ́mù ìṣí, àwọn ìṣirò tó ṣe kedere, àwọn ìdíwọ̀n tó ṣòdodo. Kò sí àwọn algorítìmù apótí dúdú.
  • Ìráàyèsí: Àwọn mẹ́tríkì tó jìnnà síi kò yẹ kó nílò ìwé-ẹ̀rí nínú ìmọ̀ sáyẹ́nsì eré ìdárayá. A ṣàlàyé àwọn èrò kedere.

Ìpilẹ̀ Ìmọ̀ Sáyẹ́nsì

Run Analytics ti kọ lórí ẹ̀wádún ìwádìí ìmọ̀ sáyẹ́nsì eré ìdárayá tí àwọn ẹlẹgbẹ́ ṣàgbéyẹ̀wò:

Critical Run Speed (CRS)

Dá lórí ìwádìí Wakayoshi et al. (1992-1993) ní Yunifásítì Osaka. CRS dúró fún iyára ìsáré tó pọ̀ jùlọ̀ tí a lè gbé lọ fún ìgbà pípẹ́ láìsí àárẹ̀, tí ó bá ìlẹ̀ẹ̀ lákítèsè lactate mu.

Ìwádìí Pàtàkì: Wakayoshi K, et al. "Determination and validity of critical velocity as an index of running performance." European Journal of Applied Physiology, 1992.

Training Stress Score (TSS)

Ìmúlò àti ọ̀nà TSS gígùn kẹ̀kẹ́ ti Dr. Andrew Coggan fún ìsáré. Ń wọn ẹrù ìdánilẹ́kọ̀ọ́ nípa dídarapọ̀ ìfararà (ní ìbámu pẹ̀lú CRS) àti iye àkókò.

Ìwádìí Pàtàkì: Coggan AR, Allen H. "Training and Racing with a Power Meter." VeloPress, 2010. Ìmúlò fún ìsáré nípasẹ̀ Run Analytics pẹ̀lú CRS gẹ́gẹ́ bí ìlẹ̀ẹ̀.

Performance Management Chart (PMC)

Àwọn mẹ́tríkì Chronic Training Load (CTL), Acute Training Load (ATL), àti Training Stress Balance (TSB). Ń tọpasẹ̀ ìlera ara, àárẹ̀, àti ìfọ̀kànbalẹ̀ ní àkókò.

Ìmúṣẹ: Apapọ̀ ìgbésẹ̀ tí a ti fi ìwọ̀n lé lọ fún ọjọ́ 42 fún CTL, ọjọ́ 7 fún ATL. TSB = CTL - ATL.

Running Efficiency & Stride Metrics

Àwọn mẹ́tríkì ìmúlò ìsáré tó dara tí ó dárúpọ̀ àkókò àti ìpele ìsáré. Àwọn olóṣìṣe ìsáré olókìkí àti àwọn olùkọ́ ní àgbáyé ń lò láti tọ́pàtọ́ àwọn ìlọsíwájú ìmọ̀-ẹrọ.

Àwọn Mẹ́tríkì Ìpilẹ̀: Running Efficiency = Àkókò + Àwọn ìgbésẹ̀. Àwọn ìpele kékeré tọ́ka sí ìmúlò tó dára sí i. Àfikún nípasẹ̀ Distance Per Stride (DPS) àti Stride Rate (SR).

Ìdàgbàsókè & Àwọn Ìmúdójúìwọ̀n

Run Analytics ń ṣàgbékalẹ̀ lọ̀wọ̀lọ̀wọ̀ pẹ̀lú àwọn ìmúdójúìwọ̀n lọ́pọ̀lọpọ̀ dá lórí ẹ̀sì àwọn olùmúlò àti ìwádìí ìmọ̀ sáyẹ́nsì eré ìdárayá tuntun jùlọ̀. Àpóòde náà ti kọ pẹ̀lú:

  • Swift & SwiftUI - Ìdàgbàsókè iOS abínibí òde-òní
  • HealthKit Integration - Ìmúdọ̀gba Apple Health tó dára
  • Core Data - Ìpamọ́ data àdúgbò tó mọ́jú
  • Swift Charts - Àwọn ìfihàn data tó lẹ́wà àti ìfọ̀wọ́bánisọ̀rọ̀
  • No Third-Party Analytics - Data ìlò rẹ wà ní àṣírí
