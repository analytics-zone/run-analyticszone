Run Analytics အတွက် ကိုယ်ရေးကိုယ်တာမူဝါဒ

နောက်ဆုံးမွမ်းမံထားသည်-ဇန်နဝါရီလ 10 ရက်၊ 2025 ခုနှစ် |ထိရောက်သည်။ ရက်စွဲ-ဇန်နဝါရီ ၁၀၊ ၂၀၂၅

နိဒါန်း

Run Analytics ("ကျွန်ုပ်တို့" "ကျွန်ုပ်တို့၏" သို့မဟုတ် "အက်ပ်") သည် သင့်ကိုယ်ရေးကိုယ်တာအချက်အလက်ကို ကာကွယ်ရန် ကတိပြုပါသည်။ ဤကိုယ်ရေးကိုယ်တာမူဝါဒ ကျွန်ုပ်တို့၏မိုဘိုင်းအပလီကေးရှင်းများ (iOS နှင့် Android) သည် သင့်ထံမှ ကျန်းမာရေးဒေတာကို မည်သို့ဝင်ရောက်၊ အသုံးပြုရန်နှင့် ကာကွယ်နည်းကို ရှင်းပြသည်။ ကိရိယာ။

အဓိက ကိုယ်ရေးကိုယ်တာ မူဝါဒ-Run Analytics သည် တစ်ခုပေါ်တွင် လုပ်ဆောင်နေသည်။သုည-ဆာဗာ၊ စက်တွင်းသီးသန့် ဗိသုကာပညာ. Apple HealthKit (iOS) သို့မဟုတ် Health Connect မှ ရယူထားသော ကျန်းမာရေးဒေတာအားလုံး (Android) သည် သင့်ရုပ်ပိုင်းဆိုင်ရာ စက်ပစ္စည်းပေါ်တွင် သီးသန့်တည်ရှိပြီး ပြင်ပဆာဗာများသို့ မည်သည့်အခါမျှ မကူးစက်နိုင်ပါ။ cloud ဝန်ဆောင်မှုများ သို့မဟုတ် တတိယအဖွဲ့အစည်းများ။

1. ကျန်းမာရေးဒေတာ သုံးစွဲခွင့်

Run Analytics သည် အသေးစိတ်အပြေးလေ့ကျင့်ခန်းကို ပံ့ပိုးပေးရန်အတွက် သင့်စက်ပစ္စည်း၏ မူရင်းကျန်းမာရေးပလက်ဖောင်းနှင့် ပေါင်းစပ်ထားသည်။ ခွဲခြမ်းစိတ်ဖြာမှု-

1.1 iOS - Apple HealthKit ပေါင်းစပ်မှု

iOS စက်ပစ္စည်းများတွင် Run Analytics နှင့် ပေါင်းစပ်ထားသည်။Apple HealthKitအပြေးလေ့ကျင့်ခန်းကိုဝင်ရောက်ရန် ဒေတာ။ ကျွန်ုပ်တို့သည် ဖတ်ရန်-သီးသန့်ဝင်ရောက်ခွင့်ကို တောင်းဆိုသည်-

  • လေ့ကျင့်ခန်းအစီအစဉ်များ-အချိန်နှင့်ကြာချိန်နှင့်အတူ လေ့ကျင့်ခန်းအစီအစဉ်များကို လုပ်ဆောင်ခြင်း။
  • အကွာအဝေး-စုစုပေါင်းပြေးအကွာအဝေး
  • နှလုံးခုန်နှုန်း-လေ့ကျင့်ခန်းလုပ်နေစဉ် နှလုံးခုန်နှုန်းဒေတာ
  • တက်ကြွသောစွမ်းအင်-လည်ပတ်နေစဉ်အတွင်း ကယ်လိုရီများလောင်ကျွမ်းခဲ့သည်။
  • အဆင့်အရေအတွက်-cadence တွက်ချက်မှုအတွက် အဆင့်ဒေတာ

Apple HealthKit လိုက်နာမှု-Run Analytics သည် Apple HealthKit လမ်းညွှန်ချက်အားလုံးကို လိုက်နာသည်။ သင့်ကျန်းမာရေးဒေတာကို သင်၏ iOS စက်ပစ္စည်းပေါ်တွင် လုံးလုံးလျားလျား လုပ်ဆောင်ပြီး ၎င်းကို ဘယ်သောအခါမှ ချန်မထားပါ။ ကျွန်ုပ်တို့သည် HealthKit ကိုဘယ်တော့မှမမျှဝေပါ။ ပြင်ပအဖွဲ့အစည်းများ၊ ကြော်ငြာပလပ်ဖောင်းများ သို့မဟုတ် ဒေတာပွဲစားများနှင့် ဒေတာ။

1.2 Android - Health Connect ပေါင်းစည်းခြင်း။

ကျန်းမာရေးဒေတာ အမျိုးအစားခွင့်ပြုချက်ရည်ရွယ်ချက်
လေ့ကျင့်ခန်းအစီအစဉ်များREAD_EXERCISEHealth Connect မှ လုပ်ဆောင်နေသည့် လေ့ကျင့်ခန်းအစီအစဉ်များကို ခွဲခြားသတ်မှတ်ပြီး တင်သွင်းရန်
အကွာအဝေးမှတ်တမ်းများREAD_DISTANCEပြေးနှုန်းစုစုပေါင်းအကွာအဝေး၊ ပိုင်းခြားခြင်းနှင့် အရှိန်တွက်ချက်ခြင်းကဲ့သို့သော အဓိကမက်ထရစ်များကို ပြသရန်
နှလုံးခုန်နှုန်းမှတ်တမ်းများREAD_HEART_RATEနှလုံးခုန်နှုန်းဇယားများကိုပြသရန်၊ လေ့ကျင့်ခန်းလုပ်နေစဉ်အတွင်း ပျမ်းမျှနှင့် အများဆုံးနှလုံးခုန်နှုန်းကို တွက်ချက်ပါ။
မြန်နှုန်းမှတ်တမ်းများREAD_SPEEDသင်၏ပြေးနှုန်းနှင့် အရှိန်ဇုန်များကို တွက်ချက်ရန်နှင့် ပြသရန်
ခြေလှမ်းများREAD_STEPSပြေးခုန်နှုန်းကို တွက်ချက်ရန် (တစ်မိနစ်လျှင် ခြေလှမ်းများ)
ကယ်လိုရီလောင်ကျွမ်းခဲ့သည်။READ_TOTAL_CALORIES_BURNEDလည်ပတ်နေစဉ်အတွင်း စွမ်းအင်အသုံးစရိတ်၏ ကျယ်ကျယ်ပြန့်ပြန့် ခြုံငုံသုံးသပ်ချက်ပေးရန်

Android ခွင့်ပြုချက်များ-ဤခွင့်ပြုချက်များကို အက်ပ်၏ပထမဆုံးစတင်ချိန်အတွင်း တောင်းဆိုထားသည်။ မင်း ဤခွင့်ပြုချက်များကို Android ဆက်တင်များ → အက်ပ်များ → ကျန်းမာရေး ချိတ်ဆက်မှု → ဖွင့်ခြင်း မှတဆင့် အချိန်မရွေး ရုပ်သိမ်းနိုင်သည်။ ပိုင်းခြားစိတ်ဖြာပါ။

1.3 ကျန်းမာရေးဒေတာကို ကျွန်ုပ်တို့အသုံးပြုပုံ

ကျန်းမာရေးဒေတာအားလုံးကို အသုံးပြုထားသည်။အောက်ပါရည်ရွယ်ချက်များအတွက်သီးသန့်:

  • လေ့ကျင့်ခန်း မျက်နှာပြင်-အသေးစိတ်တိုင်းတာမှုများ (အကွာအဝေး၊ အချိန်၊ နှလုံးခုန်နှုန်း)
  • စွမ်းဆောင်ရည်ပိုင်းခြားစိတ်ဖြာချက်-အရှိန်အဟုန်ဇုန်များ၊ စဉ်ဆက်မပြတ်ခွဲခြမ်းစိတ်ဖြာမှု၊ Threshold Pace နှင့် တွက်ချက်ပါ။ rTSS (အပြေးလေ့ကျင့်ရေးစိတ်ဖိစီးမှုရမှတ်)
  • တိုးတက်မှု ခြေရာခံခြင်း-စွမ်းဆောင်ရည် ခေတ်ရေစီးကြောင်းများ၊ ကိုယ်ရေးကိုယ်တာ အကောင်းဆုံးများနှင့် လေ့ကျင့်ခန်းများကို ပြသပါ။ အနှစ်ချုပ်
  • ဒေတာထုတ်ယူခြင်း-ကိုယ်ရေးကိုယ်တာအသုံးပြုရန်အတွက် သင်၏လေ့ကျင့်ခန်းဒေတာကို CSV ဖော်မတ်သို့ တင်ပို့ခွင့်ပြုပါ။

1.4 ဒေတာသိုလှောင်မှု

🔒 အရေးကြီးသော ကိုယ်ရေးကိုယ်တာ အာမခံချက်-

ကျန်းမာရေးဒေတာအားလုံးသည် သင့်ရုပ်ပိုင်းဆိုင်ရာစက်ပစ္စည်းပေါ်တွင် သီးသန့်ကျန်ရှိနေပါသည်။

  • iOS-ဒေတာကို iOS Core Data နှင့် UserDefaults (စက်ပေါ်တွင်သာ) အသုံးပြု၍ သိမ်းဆည်းသည်
  • Android-ဒေတာကို Android Room Database (စက်ပစ္စည်းပေါ်တွင် SQLite) အသုံးပြု၍ သိမ်းဆည်းသည်
  • ပြင်ပဆာဗာများသို့ ဒေတာမတင်ပါ။
  • အင်တာနက်ပေါ်တွင် ဒေတာမပို့ပါ။
  • cloud ထပ်တူပြုခြင်း သို့မဟုတ် ကျန်းမာရေးဒေတာ၏ အရန်ကူးခြင်း မရှိပါ။
  • သင့်ကျန်းမာရေးဒေတာကို ပြင်ပအဖွဲ့အစည်းမှ ဝင်ရောက်ခွင့်မရှိပါ။

သင့်စက်မှ ဒေတာထွက်သွားသည့်အချိန်သည် တစ်ခုတည်းသောအချိန်ဖြစ်သည်။ပြတ်သားစွာ ရွေးချယ်ပါ။သင်၏တင်ပို့ရန် လေ့ကျင့်ခန်းများကို CSV ဖော်မတ်လုပ်ပြီး ဖိုင်ကို ကိုယ်တိုင်မျှဝေပါ။

2. ခွင့်ပြုချက်များ လိုအပ်သည်။

2.1 iOS ခွင့်ပြုချက်များ

  • HealthKit အသုံးပြုခွင့်-လေ့ကျင့်ခန်းများ၊ အကွာအဝေး၊ နှလုံးခုန်နှုန်း၊ တက်ကြွသောစွမ်းအင်နှင့် ဝင်ရောက်ဖတ်ရှုပါ။ ခြေလှမ်းများ
  • ဓာတ်ပုံစာကြည့်တိုက် (ချန်လှပ်):လေ့ကျင့်ခန်း အနှစ်ချုပ်များကို ပုံများအဖြစ် သိမ်းဆည်းရန် သင်ရွေးချယ်မှသာလျှင်

HealthKit ခွင့်ပြုချက်များကို iOS ဆက်တင်များ → ကိုယ်ရေးကိုယ်တာနှင့် လုံခြုံရေး → ကျန်းမာရေး → Run တွင် အချိန်မရွေး စီမံခန့်ခွဲနိုင်ပါသည်။ ပိုင်းခြားစိတ်ဖြာပါ။

2.2 Android ခွင့်ပြုချက်များ

  • android.permission.health.READ_EXERCISE
  • android.permission.health.READ_DISTANCE
  • android.permission.health.READ_HEART_RATE
  • android.permission.health.READ_SPEED
  • android.permission.health.READ_STEPS
  • android.permission.health.READ_TOTAL_CALORIES_BURNED
  • အင်တာနက်အသုံးပြုခွင့်(INTERNET): static in-app ကိုပြသရန်အတွက်သာအသုံးပြုသည်။ အကြောင်းအရာနှင့် စာရင်းသွင်းမှု စီမံခန့်ခွဲမှု (Google Play Billing) ကို ဝင်ရောက်ကြည့်ရှုခြင်း။ ကျန်းမာရေးဒေတာကို မကူးစက်ပါ။
  • Foreground ဝန်ဆောင်မှု(FOREGROUND_SERVICE): အနာဂတ်အလားအလာအတွက် နောက်ခံ စင့်ခ်လုပ်ခြင်း အင်္ဂါရပ်များ (လောလောဆယ် အကောင်အထည်မဖော်သေးပါ)။

3. ဒေတာ ကျွန်ုပ်တို့ မစုဆောင်းပါ။

Run Analytics က ဘာလဲ။မဟုတ်ဘူးလား။စုဆောင်း၊ သိမ်းဆည်းရန် သို့မဟုတ် ပေးပို့ပါ-

  • ❌ ကိုယ်ရေးကိုယ်တာအချက်အလက် (အမည်၊ အီးမေးလ်၊ ဖုန်းနံပါတ်)
  • ❌ စက်ပစ္စည်းသတ်မှတ်မှုစနစ်များ (iOS တွင် IDFA၊ Android ရှိ ကြော်ငြာ ID)
  • ❌ တည်နေရာဒေတာ သို့မဟုတ် GPS သြဒိနိတ်များ
  • ❌ အသုံးပြုမှု ခွဲခြမ်းစိတ်ဖြာခြင်း သို့မဟုတ် အက်ပ်အပြုအမူ ခြေရာခံခြင်း။
  • ❌ ပျက်စီးမှုအစီရင်ခံစာများ သို့မဟုတ် ပြင်ပဆာဗာများသို့ ရောဂါရှာဖွေရေးဒေတာ
  • ❌ ပြင်ပအဖွဲ့အစည်း SDKs သို့မဟုတ် ခွဲခြမ်းစိတ်ဖြာမှုဝန်ဆောင်မှုများမှ မည်သည့်ဒေတာမဆို

ကျွန်တော်တိုပြင်ပအဖွဲ့အစည်း ခြေရာခံ စာကြည့်တိုက်များ လုံးဝမရှိပါ။အပါအဝင်-

  • Google Analytics / Firebase Analytics မရှိပါ။
  • Facebook SDK မရှိပါ။
  • ကြော်ငြာ SDK မရှိပါ။
  • ပျက်စီးမှုသတင်းပို့ခြင်းဝန်ဆောင်မှုများ မရှိပါ (Crashlytics၊ Sentry စသည်ဖြင့်)

4. အက်ပ်အတွင်း ဝယ်ယူမှုများနှင့် စာရင်းသွင်းမှုများ

Run Analytics သည် သင့်စက်ပစ္စည်း၏ မူရင်းငွေပေးချေမှုစနစ်မှတစ်ဆင့် စီမံခန့်ခွဲနိုင်သော အက်ပ်အတွင်းစာရင်းသွင်းမှုများကို ပံ့ပိုးပေးသည်-

4.1 iOS - App Store စာရင်းသွင်းမှုများ

iOS တွင် စာရင်းသွင်းမှုတစ်ခုကို သင်ဝယ်ယူသောအခါ-

  • Apple သည် App Store မှတဆင့် ငွေပေးချေမှု လုပ်ဆောင်ခြင်းအားလုံးကို ကိုင်တွယ်သည်။
  • ကျွန်ုပ်တို့သည် StoreKit မှတဆင့် စာရင်းသွင်းမှုအခြေအနေ (တက်ကြွ/မလှုပ်ရှား) ကိုသာ လက်ခံရရှိပါသည်။
  • သင့်ငွေပေးချေမှုအချက်အလက် (ခရက်ဒစ်ကတ်၊ ငွေပေးချေမှုလိပ်စာ) ကို ကျွန်ုပ်တို့တွင် သုံးစွဲခွင့်မရှိပါ။
  • စာရင်းသွင်းခြင်းဒေတာကို သင့်စက်ပစ္စည်းပေါ်တွင် စက်တွင်း၌ သိမ်းဆည်းထားသည်။

စာရင်းသွင်းမှုများကို စီမံပါ-

  • iOS ဆက်တင်များ → သင့်အမည် → စာရင်းသွင်းမှုများ → Run Analytics
  • သို့မဟုတ် အက်ပ်အတွင်း- ဆက်တင်များ → စာရင်းသွင်းမှုကို စီမံပါ။

4.2 Android - Google Play ငွေတောင်းခံခြင်း။

Android တွင် စာရင်းသွင်းမှုတစ်ခုကို သင်ဝယ်ယူသောအခါ-

  • Google Play သည် ငွေပေးချေမှု လုပ်ငန်းစဉ်အားလုံးကို ကိုင်တွယ်သည်။
  • ကျွန်ုပ်တို့သည် Google Play Billing API မှတဆင့် စာရင်းသွင်းမှုအခြေအနေ (တက်ကြွ/မလှုပ်ရှား) ကိုသာ လက်ခံရရှိပါသည်။
  • သင့်ငွေပေးချေမှုအချက်အလက် (ခရက်ဒစ်ကတ်၊ ငွေပေးချေမှုလိပ်စာ) ကို ကျွန်ုပ်တို့တွင် သုံးစွဲခွင့်မရှိပါ။
  • စာရင်းသွင်းခြင်းဒေတာကို သင့်စက်ပစ္စည်းပေါ်တွင် စက်တွင်း၌ သိမ်းဆည်းထားသည်။

စာရင်းသွင်းမှုများကို စီမံပါ-

  • Google Play Store → အကောင့် → စာရင်းသွင်းမှုများ → Run Analytics
  • သို့မဟုတ် အက်ပ်အတွင်း- ဆက်တင်များ → စာရင်းသွင်းမှုကို စီမံပါ။

5. ဒေတာသိမ်းဆည်းခြင်းနှင့် ဖျက်ခြင်း

5.1 ဒေတာသိမ်းဆည်းခြင်း

  • ကျန်းမာရေးဒေတာကို သင့်စက်ပေါ်တွင် သိမ်းဆည်းထားသည်။အကန့်အသတ်မရှိ၎င်းကို သင်ကိုယ်တိုင် ဖျက်သည်အထိ
  • သမိုင်းဆိုင်ရာ စွမ်းဆောင်ရည် ခြေရာခံခြင်းနှင့် ခွဲခြမ်းစိတ်ဖြာမှုများကို ပံ့ပိုးပေးရန်အတွက် လေ့ကျင့်ခန်းဒေတာကို သိမ်းဆည်းထားသည်။

5.2 ဒေတာဖျက်ခြင်း။

သင့်ဒေတာကို အချိန်မရွေး ဖျက်နိုင်သည်-

နည်းလမ်း 1- တစ်ဦးချင်းလေ့ကျင့်ခန်းများကို ဖျက်ပါ။

  • လေ့ကျင့်ခန်းအသေးစိတ်စခရင်ကိုဖွင့်ပါ။
  • ဖျက်ရန် ခလုတ်ကို နှိပ်ပါ (အမှိုက်ပုံး)
  • ဖျက်ကြောင်းအတည်ပြုပါ။

နည်းလမ်း 2- အက်ပ်ဒေတာအားလုံးကို ရှင်းလင်းပါ။

  • iOS-အက်ပ်ကို ဖျက်ပြီး ပြန်လည်ထည့်သွင်းပါ (ဒေသခံဒေတာအားလုံးကို ဖယ်ရှားလိုက်သည်)
  • Android-ဆက်တင်များ → အက်ပ်များ → Run Analytics → သိုလှောင်မှု → ဒေတာကို ရှင်းလင်းပါ။

နည်းလမ်း 3- အက်ပ်ကို ဖြုတ်ပါ။

  • Run Analytics ကို ဖြုတ်ခြင်းသည် စက်တွင်းဒေတာအားလုံးကို အလိုအလျောက် ဖျက်ပေးပါသည်။

နည်းလမ်း 4- ကျန်းမာရေးခွင့်ပြုချက်များကို ရုတ်သိမ်းပါ။

  • iOS-ဆက်တင်များ → ကိုယ်ရေးကိုယ်တာနှင့် လုံခြုံရေး → ကျန်းမာရေး → Run Analytics → အားလုံးကို ပိတ်ပါ။ အမျိုးအစားများ
  • Android-ဆက်တင်များ → အက်ပ်များ → ကျန်းမာရေး ချိတ်ဆက်မှု → Run Analytics → ခွင့်ပြုချက်အားလုံးကို ရုပ်သိမ်းပါ။

6. Data လုံခြုံရေး

သင့်စက်တွင် ဒေတာအားလုံး ကျန်ရှိနေသော်လည်း ဒေတာလုံခြုံရေးကို ကျွန်ုပ်တို့ အလေးအနက်ထားပါသည်-

6.1 လုံခြုံရေးဆောင်ရွက်မှုများ

  • iOS လုံခြုံရေး-iOS Core Data ကို အသုံးပြု၍ သိမ်းဆည်းထားသည့် ဒေတာအားလုံးကို iOS သော့ချိတ်ဖြင့် ကာကွယ်ထားပြီး၊ စက်ပစ္စည်း ကုဒ်ဝှက်ခြင်း။ စက်ပစ္စည်းလော့ခ်ချထားသည့်အခါ ဒေတာကို ကာကွယ်ထားသည်။
  • Android လုံခြုံရေး-Room Database တွင် သိမ်းဆည်းထားသည့် ဒေတာအားလုံးကို Android မှ ကာကွယ်ပေးထားသည်။ built-in လုံခြုံရေးနှင့် app sandbox ။
  • ကွန်ရက် ထုတ်လွှင့်ခြင်း မရှိပါ-ကျန်းမာရေးဒေတာသည် သင့်စက်ပစ္စည်းကို ဘယ်သောအခါမှ ချန်မထားဘဲ ဖယ်ရှားလိုက်ပါ။ ဂီယာလုံခြုံရေးအန္တရာယ်များ
  • အက်ပ် Sandboxing-iOS နှင့် Android အက်ပ်သဲပုံးများသည် အခြားအက်ပ်များကို Run ခြင်းသို့ ဝင်ရောက်ခြင်းမှ တားဆီးသည်။ ပိုင်းခြားစိတ်ဖြာမှုဒေတာ
  • လုံခြုံသောသိုလှောင်မှု-စက်ပစ္စည်းအထောက်အထားစိစစ်ခြင်းမရှိဘဲ ကျန်းမာရေးဒေတာကို ဝင်ရောက်ကြည့်ရှု၍မရပါ။ (လျှို့ဝှက်ကုဒ်၊ Face ID၊ Touch ID၊ လက်ဗွေ၊ မျက်နှာဖြင့် လော့ခ်ဖွင့်ခြင်း)

6.2 သင်၏တာဝန်

သင့်ဒေတာကို ကာကွယ်ရန်-

  • ခိုင်မာသော လျှို့ဝှက်ကုဒ်/ဇီဝတိုင်းတာမှုဖြင့် သင့်စက်ပစ္စည်းကို လော့ခ်ချထားပါ။
  • နောက်ဆုံးပေါ် လုံခြုံရေးပြင်ဆင်မှုများဖြင့် သင်၏ OS ကို အပ်ဒိတ်လုပ်ထားပါ။
  • iOS-သင့်စက်ကို jailbreak မလုပ်ပါနှင့်
  • Android-သင့်စက်ကို root မလုပ်ပါနှင့်

7. ဒေတာမျှဝေခြင်းနှင့် တတိယပါတီများ

Run Analytics သည် သင့်ကျန်းမာရေးဒေတာကို မည်သည့်ပြင်ပအဖွဲ့အစည်းနှင့်မျှ မမျှဝေပါ။

7.1 ဒေတာမျှဝေခြင်း မရှိပါ။

  • သင့်ဒေတာကို ကျွန်ုပ်တို့ မရောင်းပါ။
  • သင့်ဒေတာကို ကြော်ငြာရှင်များနှင့် မျှဝေခြင်းမပြုပါ။
  • ကျွန်ုပ်တို့သည် သင်၏ဒေတာများကို ခွဲခြမ်းစိတ်ဖြာမှုကုမ္ပဏီများအား ပေးဆောင်ခြင်းမရှိပါ။
  • ကျွန်ုပ်တို့သည် ဆိုရှယ်မီဒီယာပလက်ဖောင်းများနှင့် ပေါင်းစည်းခြင်းမပြုပါ။

7.2 CSV တင်ပို့ခြင်း (အသုံးပြုသူ-အစပြုသူသာ)

သင့်စက်မှ ဒေတာထွက်သွားသည့် တစ်ခုတည်းသောနည်းလမ်းမှာ မည်သည့်အချိန်တွင်ဖြစ်သည်။သင်အတိအလင်း-

  1. ဆက်တင်များ → Raw Data Export သို့ သွားပါ။
  2. CSV ဖိုင်ကို ဖန်တီးပါ။
  3. CSV ဖိုင်ကို သင့်စက်ပစ္စည်း၏ မျှဝေမှုမီနူး (အီးမေးလ်၊ cloud သိုလှောင်မှု၊ စာတိုပေးပို့ခြင်းအက်ပ်) မှတစ်ဆင့် မျှဝေရန် ရွေးချယ်ပါ။

၎င်းသည် သင့်ထိန်းချုပ်မှုအောက်တွင် လုံးလုံးလျားလျားဖြစ်သည်။

8. ကလေးများ၏ ကိုယ်ရေးကိုယ်တာ

Run Analytics သည် အသက် 13 နှစ်အောက် ကလေးများထံမှ ဒေတာကို သိလျက်နှင့် မစုဆောင်းပါ။ အက်ပ်က မပါဘူး။ အသက်အရွယ်အချက်အလက်ကို တောင်းဆိုသော်လည်း မိဘများသည် ၎င်းတို့၏ကလေးများ၏ ကျန်းမာရေးခြေရာခံခြင်းအသုံးပြုမှုကို ကြီးကြပ်သင့်သည်။ လျှောက်လွှာများ။

အသက် 13 နှစ်အောက် ကလေးတစ်ဦးသည် Run Analytics ကို အသုံးပြုခဲ့သည်ဟု သင်ယုံကြည်ပါက၊ ကျွန်ုပ်တို့ထံ ဆက်သွယ်ပါ၊ ကျွန်ုပ်တို့မှ ကူညီဆောင်ရွက်ပေးပါမည်။ စက်တွင်းရှိ ဒေတာအားလုံးကို ဖျက်ပစ်ကြောင်း သေချာပါစေ။

9. နိုင်ငံတကာဒေတာလွှဲပြောင်းမှုများ

မသက်ဆိုင်ပါ။ကျန်းမာရေးဒေတာအားလုံးသည် သင့်စက်ပစ္စည်းပေါ်တွင် သီးသန့်ကျန်ရှိနေသောကြောင့် (iOS သို့မဟုတ် Android) နှင့် ဆာဗာများသို့ ဘယ်သောအခါမှ မကူးစက်ပါ၊ နိုင်ငံတကာ ဒေတာလွှဲပြောင်းမှုများ မရှိပါ။

10. သင်၏အခွင့်အရေးများ (GDPR၊ CCPA လိုက်နာမှု)

Run Analytics သည် ဆာဗာများပေါ်တွင် ကိုယ်ရေးကိုယ်တာအချက်အလက်များကို မစုဆောင်းထားသော်လည်း၊ ကျွန်ုပ်တို့သည် သင်၏ဒေတာကိုယ်ရေးကိုယ်တာအခွင့်အရေးများကို လေးစားပါသည်-

10.1 GDPR အခွင့်အရေးများ (ဥရောပအသုံးပြုသူများ)

  • ဝင်ရောက်ခွင့်-သင့်ဒေတာအားလုံးကို အက်ပ်အတွင်း အချိန်မရွေး ဝင်ရောက်အသုံးပြုနိုင်သည်။
  • ဖျက်ပိုင်ခွင့်-အပိုင်း 5.2 တွင်ဖော်ပြထားသော နည်းလမ်းများကို အသုံးပြု၍ ဒေတာကို ဖျက်ပါ။
  • သယ်ဆောင်ရလွယ်ကူရန် ညာဘက်-သင့်ဒေတာကို CSV ဖော်မတ်သို့ တင်ပို့ပါ (ဆက်တင်များ → ကုန်ကြမ်းဒေတာ ထုတ်ယူခြင်း)
  • လုပ်ဆောင်ခြင်းကို ကန့်သတ်ပိုင်ခွင့်-ဒေတာအသစ်ဝင်ရောက်ခွင့်ကို ရပ်တန့်ရန် ကျန်းမာရေးခွင့်ပြုချက်များကို ရုပ်သိမ်းပါ။

10.2 CCPA အခွင့်အရေးများ (California အသုံးပြုသူများ)

  • သိပိုင်ခွင့်-ဤမူဝါဒသည် ဝင်ရောက်အသုံးပြုသည့် ဒေတာအားလုံးကို ထုတ်ဖော်ပြသပြီး ၎င်းကိုအသုံးပြုပုံကို ဖော်ပြသည်။
  • ဖျက်ပိုင်ခွင့်-အပိုင်း 5.2 တွင်ဖော်ပြထားသော နည်းလမ်းများကို အသုံးပြု၍ ဒေတာကို ဖျက်ပါ။
  • ရောင်းချခြင်းမှ ထွက်ခွာခွင့်-မသက်ဆိုင်ပါ (ဒေတာကို ကျွန်ုပ်တို့ ဘယ်တော့မှ မရောင်းပါ)

11. ဤကိုယ်ရေးကိုယ်တာမူဝါဒကို ပြောင်းလဲမှုများ

ကျွန်ုပ်တို့သည် ဤကိုယ်ရေးကိုယ်တာမူဝါဒကို အခါအားလျော်စွာ အပ်ဒိတ်လုပ်နိုင်ပါသည်။ ကျွန်ုပ်တို့ အပြောင်းအလဲများ ပြုလုပ်သောအခါ-

  • ဤမူဝါဒ၏ထိပ်ရှိ "နောက်ဆုံးမွမ်းမံမှု" ရက်စွဲကို ပြန်လည်ပြင်ဆင်ပါမည်။
  • အက်ပ်အတွင်း သိသာထင်ရှားသောပြောင်းလဲမှုများကို ကြေငြာပါမည်။
  • အပြောင်းအလဲများပြီးနောက် အက်ပ်ကို ဆက်လက်အသုံးပြုခြင်းသည် အပ်ဒိတ်လုပ်ထားသောမူဝါဒကို လက်ခံခြင်းဖြစ်သည်။

ကျွန်ုပ်တို့သည် သင့်ကိုယ်ရေးကိုယ်တာအချက်အလက်ကို မည်သို့ကာကွယ်ရမည်ကို သိရှိစေရန်အတွက် ဤမူဝါဒကို အခါအားလျော်စွာ ပြန်လည်သုံးသပ်ရန် အကြံပြုအပ်ပါသည်။

၁၂။ကျွန်ုပ်တို့ကို ဆက်သွယ်ပါ။

သင့်တွင် ဤကိုယ်ရေးကိုယ်တာမူဝါဒ သို့မဟုတ် သင့်ဒေတာနှင့်ပတ်သက်သည့် မေးခွန်းများ၊ စိုးရိမ်မှုများ သို့မဟုတ် တောင်းဆိုမှုများရှိပါက ကိုယ်ရေးကိုယ်တာ-

  • အီးမေးလ်-analyticszone@onmedic.org
  • ဝဘ်ဆိုဒ်-https://runanalytics.app

တုံ့ပြန်ချိန်-ကျွန်ုပ်တို့သည် လုပ်ငန်း 7 ရက်အတွင်း ကိုယ်ရေးကိုယ်တာ စုံစမ်းမေးမြန်းမှုများအားလုံးကို တုံ့ပြန်ရန် ရည်ရွယ်ပါသည်။

13. ဥပဒေလိုက်နာမှု

Run Analytics သည်-

  • iOS-Apple App Store ပြန်လည်သုံးသပ်ခြင်း လမ်းညွှန်ချက်များ၊ Apple HealthKit လမ်းညွှန်ချက်များ
  • Android-Google Play Developer Program မူဝါဒများ၊ Android Health Connect လမ်းညွှန်ချက်များ
  • အထွေထွေဒေတာကာကွယ်ရေးစည်းမျဉ်း (GDPR)
  • ကယ်လီဖိုးနီးယားစားသုံးသူလျှို့ဝှက်ရေးဥပဒေ (CCPA)
  • ကလေးများ၏ အွန်လိုင်း ကိုယ်ရေးကိုယ်တာ ကာကွယ်ရေးဥပဒေ (COPPA)

အကျဉ်းချုပ်

ရိုးရှင်းသောစည်းမျဥ်းများတွင်-

  • ✅ကျွန်ုပ်တို့ ဝင်ရောက်ကြည့်ရှုနိုင်သည်-Apple HealthKit (iOS) သို့မဟုတ် Health Connect မှ လေ့ကျင့်ခန်းဒေတာကို လုပ်ဆောင်နေသည်။ (Android)
  • ✅သိမ်းဆည်းသည့်နေရာတွင်သင့်စက်တွင်သာ (iOS Core Data သို့မဟုတ် Android Room Database)
  • ✅ဘယ်သွားလဲ-မနောကံ။ သင့်စက်ကို ဘယ်တော့မှ မထားခဲ့ပါ။
  • ✅ဘယ်သူမြင်လဲသင်သာလျှင်။
  • ✅ဖျက်နည်း-အက်ပ်ဒေတာကို ရှင်းလင်းပါ သို့မဟုတ် အက်ပ်ကို အချိန်မရွေး ဖြုတ်လိုက်ပါ။
