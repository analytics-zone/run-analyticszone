Sekretesspolicy för Run Analytics

Senast uppdaterad:10 januari 2025 |Effektiv Datum:10 januari 2025

Introduktion

Run Analytics ("vi", "vår" eller "appen") har åtagit sig att skydda din integritet. Denna integritetspolicy förklarar hur våra mobilapplikationer (iOS och Android) kommer åt, använder och skyddar hälsodata från din enhet.

Viktig sekretessprincip:Run Analytics fungerar på ennoll-server, endast lokal arkitektur. All hälsodata som nås från Apple HealthKit (iOS) eller Health Connect (Android) förblir uteslutande på din fysiska enhet och överförs aldrig till externa servrar, molntjänster eller tredje part.

1. Tillgång till hälsodata

Run Analytics integreras med din enhets inhemska hälsoplattform för att ge detaljerad löpträning analys:

1.1 iOS - Apple HealthKit Integration

På iOS-enheter integreras Run Analytics medApple HealthKitför att komma åt löpträning data. Vi begär skrivskyddad åtkomst till:

  • Träningspass:Löpande träningspass med tid och varaktighet
  • Avstånd:Totala löpsträckor
  • Puls:Pulsdata under träningspass
  • Aktiv energi:Förbrända kalorier under löppass
  • Antal steg:Stegdata för kadensberäkning

Apple HealthKit-överensstämmelse:Run Analytics följer alla Apple HealthKit-riktlinjer. Dina hälsodata behandlas helt och hållet på din iOS-enhet och lämnar den aldrig. Vi delar aldrig HealthKit data med tredje part, reklamplattformar eller datamäklare.

1.2 Android - Health Connect Integration

Hälsodatatyp Tillstånd Syfte
Träningspass READ_EXERCISE För att identifiera och importera löpträningspass från Health Connect
Distansrekord READ_DISTANCE För att visa nyckelmått som total distans per löpning, delningar och beräkna tempo
Pulsrekord READ_HEART_RATE För att visa pulsdiagram, beräkna medel- och maxpuls under träningspass
Hastighetsrekord READ_SPEED För att beräkna och visa ditt löptempo och tempozoner
Steg READ_STEPS För att beräkna löpkadens (steg per minut)
Förbrända kalorier READ_TOTAL_CALORIES_BURNED För att ge en heltäckande översikt över energiförbrukningen under löppass

Android-behörigheter:Dessa behörigheter begärs under appens första lansering. Du kan återkalla dessa behörigheter när som helst via Android-inställningar → Appar → Health Connect → Kör Analytics.

1.3 Hur vi använder hälsodata

Alla hälsodata användsuteslutande för följande ändamål:

  • Träningsdisplay:Visa dina löpsessioner med detaljerad statistik (avstånd, tid, tempo, puls)
  • Prestandaanalys:Beräkna taktzoner, kadensanalys, tröskeltempo och rTSS (Stresspoäng för löpträning)
  • Förloppsspårning:Visa prestandatrender, personbästa och träning sammanfattningar
  • Dataexport:Låter dig exportera dina träningsdata till CSV-format för personligt bruk

1.4 Datalagring

🔒 KRITISK SEKRETESSGARANTI:

All hälsodata finns kvar uteslutande på din fysiska enhet.

  • iOS:Data lagras med iOS Core Data och UserDefaults (endast på enheten)
  • Android:Data lagras med Android Room Database (på enheten SQLite)
  • INGEN data laddas upp till externa servrar
  • INGA data överförs över internet
  • INGEN molnsynkronisering eller säkerhetskopiering av hälsodata
  • INGEN tredje parts tillgång till dina hälsodata

Den enda gången data lämnar din enhet är närDU väljer uttryckligenatt exportera din träningspass till CSV-format och dela filen själv.

2. Behörigheter krävs

2.1 iOS-behörigheter

  • Tillgång till HealthKit:Läsåtkomst till träningspass, distans, puls, aktiv energi och Steg
  • Fotobibliotek (valfritt):Endast om du väljer att spara träningssammanfattningar som bilder

Du kan hantera HealthKit-behörigheter när som helst i iOS-inställningar → Sekretess och säkerhet → Hälsa → Kör Analytics.

2.2 Android-behörigheter

  • android.permission.health.READ_EXERCISE
  • android.permission.health.READ_DISTANCE
  • android.permission.health.READ_HEART_RATE
  • android.permission.health.READ_SPEED
  • android.permission.health.READ_STEPS
  • android.permission.health.READ_TOTAL_CALORIES_BURNED
  • Tillgång till Internet(INTERNET): Används endast för att visa statisk in-app innehåll och åtkomst till prenumerationshantering (Google Play Billing). Inga hälsouppgifter överförs.
  • Förgrundsservice(FOREGROUND_SERVICE): För potentiell framtid bakgrundssynkroniseringsfunktioner (inte implementerade för närvarande).

3. Data vi INTE samlar in

Run Analytics gör detINTEsamla in, lagra eller överföra:

  • ❌ Personlig identifieringsinformation (namn, e-post, telefonnummer)
  • ❌ Enhetsidentifierare (IDFA på iOS, reklam-ID på Android)
  • ❌ Platsdata eller GPS-koordinater
  • ❌ Användningsanalys eller appbeteendespårning
  • ❌ Kraschrapporter eller diagnostisk data till externa servrar
  • ❌ All data via tredjeparts SDK:er eller analystjänster

Vi användernoll spårningsbibliotek från tredje partinklusive:

  • Ingen Google Analytics/Firebase Analytics
  • Ingen Facebook SDK
  • Inga annonserings-SDK:er
  • Inga kraschrapporteringstjänster (Crashlytics, Sentry, etc.)

4. Inköp och prenumerationer i appen

Run Analytics erbjuder valfria prenumerationer i appen som hanteras via din enhets inbyggda betalningssystem:

4.1 iOS - App Store-abonnemang

När du köper ett abonnemang på iOS:

  • Apple hanterar all betalningshantering genom App Store
  • Vi får endast prenumerationsstatus (aktiv/inaktiv) genom StoreKit
  • Vi har INTE tillgång till din betalningsinformation (kreditkort, faktureringsadress)
  • Prenumerationsdata lagras lokalt på din enhet

Hantera prenumerationer:

  • iOS Inställningar → Ditt namn → Prenumerationer → Run Analytics
  • Eller i appen: Inställningar → Hantera prenumeration

4.2 Android – Google Play Billing

När du köper ett abonnemang på Android:

  • Google Play hanterar all betalningshantering
  • Vi får endast prenumerationsstatusen (aktiv/inaktiv) via Google Play Billing API
  • Vi har INTE tillgång till din betalningsinformation (kreditkort, faktureringsadress)
  • Prenumerationsdata lagras lokalt på din enhet

Hantera prenumerationer:

  • Google Play Butik → Konto → Prenumerationer → Run Analytics
  • Eller i appen: Inställningar → Hantera prenumeration

5. Datalagring och radering

5.1 Datalagring

  • Hälsodata lagras på din enhetpå obestämd tidtills du raderar det manuellt
  • Träningsdata behålls för att ge historisk prestationsspårning och analys

5.2 Dataradering

Du kan radera dina uppgifter när som helst:

Metod 1: Ta bort individuella träningspass

  • Öppna skärmen för träningsdetaljer
  • Tryck på raderingsknappen (papperskorgen)
  • Bekräfta borttagning

Metod 2: Rensa alla appdata

  • iOS:Ta bort och installera om appen (all lokal data tas bort)
  • Android:Inställningar → Appar → Run Analytics → Lagring → Rensa data

Metod 3: Avinstallera appen

  • Om du avinstallerar Run Analytics raderas all lokal data automatiskt

Metod 4: Återkalla hälsotillstånd

  • iOS:Inställningar → Sekretess och säkerhet → Hälsa → Run Analytics → Stäng av alla Kategorier
  • Android:Inställningar → Appar → Health Connect → Run Analytics → Återkalla alla behörigheter

6. Datasäkerhet

Vi tar datasäkerhet på allvar, även om all data finns kvar på din enhet:

6.1 Säkerhetsåtgärder

  • iOS Säkerhet:All data som lagras med iOS Core Data skyddas av iOS Nyckelring och enhetskryptering. Data skyddas när enheten är låst.
  • Android-säkerhet:All data som lagras i Room Database är skyddad av Androids inbyggd säkerhet och app-sandlåda.
  • Ingen nätverksöverföring:Hälsodata lämnar aldrig din enhet, vilket eliminerar överföringssäkerhetsrisker
  • App Sandboxing:iOS- och Android-appsandlådor hindrar andra appar från att komma åt Run Analysdata
  • Säker lagring:Hälsodata kan inte nås utan enhetsautentisering (lösenkod, Face ID, Touch ID, fingeravtryck, ansiktsupplåsning)

6.2 Ditt ansvar

Så här skyddar du din data:

  • Håll din enhet låst med ett starkt lösenord/biometri
  • Håll ditt operativsystem uppdaterat med de senaste säkerhetsuppdateringarna
  • iOS:Jailbreak inte din enhet
  • Android:Root inte din enhet

7. Datadelning och tredje part

Run Analytics delar INTE dina hälsodata med någon tredje part.

7.1 Ingen datadelning

  • Vi säljer inte dina uppgifter
  • Vi delar inte dina uppgifter med annonsörer
  • Vi tillhandahåller inte dina uppgifter till analysföretag
  • Vi integrerar inte med sociala medieplattformar

7.2 CSV-export (endast användarinitierad)

Det enda sättet som data lämnar din enhet är närDUuttryckligen:

  1. Navigera till Inställningar → Export av rådata
  2. Generera en CSV-fil
  3. Välj att dela CSV-filen via din enhets delningsmeny (e-post, molnlagring, meddelandeappar)

Detta är helt under din kontroll.

8. Barns integritet

Run Analytics samlar inte medvetet in data från barn under 13 år. Det gör inte appen begär åldersinformation, men föräldrar bör övervaka sina barns användning av hälsospårning applikationer.

Om du tror att ett barn under 13 år har använt Run Analytics, vänligen kontakta oss, så hjälper vi dig se till att all lokal data raderas från enheten.

9. Internationella dataöverföringar

Ej tillämpligt.Eftersom all hälsodata finns kvar uteslutande på din enhet (iOS eller Android) och sänds aldrig till servrar, det finns inga internationella dataöverföringar.

10. Dina rättigheter (GDPR, CCPA-efterlevnad)

Även om Run Analytics inte samlar in personuppgifter på servrar, respekterar vi dina rättigheter för datasekretess:

10.1 GDPR-rättigheter (europeiska användare)

  • Rätt till tillgång:All din data är tillgänglig i appen när som helst
  • Rätt till radering:Radera data med de metoder som beskrivs i avsnitt 5.2
  • Rätt till portabilitet:Exportera dina data till CSV-format (Inställningar → Export av rådata)
  • Rätt att begränsa behandlingen:Återkalla hälsobehörigheter för att stoppa ny dataåtkomst

10.2 CCPA-rättigheter (användare i Kalifornien)

  • Rätt att veta:Denna policy avslöjar all data som du får åtkomst till och hur den används
  • Rätt att radera:Radera data med de metoder som beskrivs i avsnitt 5.2
  • Rätt att välja bort försäljning:Ej tillämpligt (vi säljer aldrig data)

11. Ändringar av denna integritetspolicy

Vi kan uppdatera denna integritetspolicy då och då. När vi gör ändringar:

  • Datumet "Senast uppdaterad" högst upp i denna policy kommer att revideras
  • Betydande förändringar kommer att meddelas i appen
  • Fortsatt användning av appen efter ändringar utgör godkännande av den uppdaterade policyn

Vi rekommenderar att du granskar denna policy regelbundet för att hålla dig informerad om hur vi skyddar din integritet.

12.Kontakta oss

Om du har frågor, funderingar eller förfrågningar angående denna integritetspolicy eller dina uppgifter integritet:

  • E-post:analyticszone@onmedic.org
  • Webbplats: https://runanalytics.app

Svarstid:Vi strävar efter att svara på alla sekretessförfrågningar inom 7 arbetsdagar.

13. Laglig efterlevnad

Run Analytics uppfyller:

  • iOS:Apple App Store Review Guidelines, Apple HealthKit Guidelines
  • Android:Programpolicyer för utvecklare för Google Play, riktlinjer för Android Health Connect
  • General Data Protection Regulation (GDPR)
  • California Consumer Privacy Act (CCPA)
  • Children's Online Privacy Protection Act (COPPA)

Sammanfattning

  • ✅Vad vi kommer åt:Kör träningsdata från Apple HealthKit (iOS) eller Health Connect (Android)

  • ✅Vem ser det:Bara du.
  • ✅Så här tar du bort det:Rensa appdata eller avinstallera appen när som helst.
