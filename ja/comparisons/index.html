Run Analytics と他の実行中のアプリ - 機能の比較

Run Analytics と Strava、TrainingPeaks、Final Surge、その他のランニング トラッキングとの比較 プラットフォーム

ランニングに特化した分析が必要な理由

Strava や TrainingPeaks などの一般的なフィットネス アプリはサイクリングやランニングに優れていますが、走っている さまざまな指標が必要です。クリティカル ラン スピード (CRS)、ペースベースのトレーニング ゾーン、およびストライド メカニズムはマルチスポーツ プラットフォームで適切にサポートされていません。 Run Analytics は、以下の用途に特化して構築されています。 トラックやトレイルランニングのアスリート向けに設計された指標を備えたランニング。

Run Analytics vs Strava

Strava の優れている点

  • ソーシャル機能:クラブ、セグメント、称賛、アクティビティ フィード
  • マルチスポーツの追跡:ランニング、サイクリング、ランニング、ハイキングなど。
  • 無料利用枠:カジュアルアスリート向けの豊富な無料機能
  • 大規模なユーザーベース:世界中の何百万人ものアスリートとつながる
  • Apple Watchの統合:ワークアウトから直接同期

Run Analytics の優れた点

  • ランニング固有の指標:CRS、rTSS、トラック向けペースゾーン
  • トレーニング負荷分析:CTL/ATL/TSB を含む (Strava にはありません)
  • 自動rTSS:手動データ入力は不要、CRS + ペースから計算
  • ストライドの仕組み:DPS、ストライドレート、ストライドインデックスの追跡
  • トレーニングゾーン:あなたの生理機能に基づいてカスタマイズされた 6 つのペースゾーン

評決: Run Analytics vs Strava

次の場合には Strava を使用してください。ソーシャル機能、マルチスポーツの追跡、または無料のカジュアルな追跡が必要です。 Strava は、ワークアウトの記録や友人とのつながりに最適です。

次の場合は Run Analytics を使用してください。実行パフォーマンスを真剣に考えており、CRS ベースのゾーンが必要な場合、 自動rTSS、トレーニング負荷管理(CTL/ATL/TSB)。 Strava は TSS の実行を計算しません。 PMC メトリクスを提供します。

両方を使用します。多くのランナーはソーシャル共有に Strava を使用し、Run Analytics を使用しています。 パフォーマンスの追跡。それらは互いにうまく補完し合います。

Run Analytics vs TrainingPeaks

TrainingPeaks が得意なこと

  • 包括的なPMC:業界標準のCTL/ATL/TSBチャート
  • ワークアウトライブラリ:何千もの構造化されたトレーニング
  • コーチの統合:プロのコーチとアスリートのプラットフォーム
  • マルチスポーツトレーニング:トライアスロンを中心とした 3 つのスポーツすべて
  • 高度な分析:バイク/ランニングのパワー、心拍数ゾーン

Run Analytics の優れた点

  • 自動CRSテスト:ゾーン生成機能を備えた内蔵CRS計算機
  • ランニング用に付属のPMC:TrainingPeaks では、PMC に月額 20 ドルのプレミアムが必要です
  • 簡素化されたインターフェース:Run Analytics は圧倒的ではなく、ランニングに重点を置いています
  • Apple Watch ネイティブ:Apple Health 経由で直接同期 (Garmin は不要)
  • 低コスト:TrainingPeaks プレミアムは月額 $3.99 対 $20/月

評決：Run Analytics vs TrainingPeaks

次の場合に TrainingPeaks を使用します。あなたは複数のスポーツ イベントに向けてトレーニングをしているトライアスリートです。コーチが必要です TrainingPeaks を使用するか、構造化されたバイク/ラン ワークアウトが必要です。 TrainingPeaks は包括的な分野で優れています トライアスロンのトレーニング。

次の場合は Run Analytics を使用してください。あなたはランナー (トライアスリートではありません) であるか、ランニング固有の指標が必要です 月額 20 ドルを支払うことなく。 Run Analytics は、CTL/ATL/TSB および rTSS の計算を、Run Analytics よりも 80% 低いコストで提供します。 トレーニングピークスプレミアム。

主な違い:TrainingPeaks はコーチング機能を備えたマルチスポーツです。走る Analytics はネイティブ CRS サポートと手頃な価格の PMC アクセスを備えた実行専用です。

Run Analytics vs ファイナルサージ

Final Surge が得意とするもの

  • コーチプラットフォーム:コーチとアスリートの関係を重視したデザイン
  • TSS サポート:TSS 計算の実行が可能
  • マルチスポーツ:ランニング、ランニング、サイクリング、筋力
  • トレーニング計画:カレンダーベースのトレーニング計画
  • コミュニケーションツール:アプリ内コーチメッセージング

Run Analytics の優れた点

  • ネイティブ CRS テスト:手入力ではなく、内蔵の計算機

  • 個々のアスリートの焦点:セルフコーチングのランナー向けに設計
  • Apple Watchの統合:ヘルスケアアプリのシームレスな同期
  • 特化したランニング:マルチスポーツ機能によって薄められない

評決: Run Analytics vs Final Surge

次の場合にファイナル サージを使用します。Final Surge を使用するコーチがいる、またはアスリートを指導しているとします。 Final Surge は、第一にコーチング プラットフォーム、第二にアスリート アプリです。

次の場合は Run Analytics を使用してください。あなたは自己指導を行っており、自動分析を必要としています。プロテクト18X 手動ログは必要ありません。すべてが Apple Watch から自動的に同期されます。

主な違い:Final Surge はコーチ中心です。プロテクト18Xは アスリート中心で自動化に重点を置いています。

Run Analytics のユニークな点

1. ファーストクラスのCRSサポート

プロテクト18Xは唯一のアプリネイティブのCRSテスト計算機付き。 5K を入力すると、 3,000 回、即座に取得:

  • CRS ペース (例: 1:49/100m)
  • 6つのパーソナライズされたトレーニングゾーン
  • すべてのワークアウトに対する rTSS の自動計算
  • ゾーンベースのワークアウト分析

競合他社:手動のゾーン設定が必要か、ゾーンの実行をサポートしていません 全然。

2. ランニング用自動rTSS

ほとんどのアプリでは、TSS を手動で入力する必要があるか、TSS の実行をまったく計算しません。プロテクト18X:

  • すべての Apple Watch ワークアウトから rTSS を自動的に計算します
  • CRS + ワークアウトペースを使用して強度係数を決定します
  • 手動ログは必要ありません。CRS を一度設定すれば、その後は忘れてください。

ストラバ:TSS の実行中は計算されません。トレーニングピーク:月額 20 ドルのプレミアムが必要です。ファイナルサージ:手動入力が必要です。

3. 手頃な価格の PMC アクセス

性能管理表（CTL/ATL/TSB）はトレーニング負荷に必須 管理、ただし他のプラットフォームでは高価です:

  • プロテクト18X:月額 $3.99 で含まれます
  • トレーニングピーク:月額 20 ドルのプレミアムが必要 (年間 240 ドル)
  • ストラバ:どの価格でも入手できません
  • ファイナルサージ:$10/月のプレミアム ($120/年)

Run Analytics は、CTL/ATL/TSB を提供します。コストが 80% 削減よりも トレーニングピーク。

4.Apple Watchネイティブ

Run Analytics は Apple Health と直接同期します。Garmin ウォッチは必要ありません。

  • あらゆる Apple Watch (シリーズ 2 以降) で動作します。
  • ヘルスケアアプリからのワークアウトの自動インポート
  • キロごとのペース、ストライド数、ランニング効率
  • 追加のハードウェアは必要ありません

トレーニングピーク:Garmin/Wahoo デバイス (200 ～ 800 ドル) が必要です。ストラバ:Apple Watch で動作しますが、ランニング分析機能はありません。

5.ランニングのみに集中

マルチスポーツ アプリはあらゆることをやろうとしますが、ランニングのパフォーマンスが低下することがよくあります。プロテクト18Xは建てられた ランニング専用:

  • トラックトレーニングワークフローを中心に設計されたインターフェース
  • ランナーに関連する指標 (CRS、rTSS、ストライドメカニクス)
  • 自転車/ランニング/ハイキングの追跡による機能の肥大化はありません
  • 実行の改善に重点を置いたアップデート

よくある質問

Run Analytics と Strava/TrainingPeaks は使用できますか?

はい、多くのランナーが両方を使用しています。パフォーマンス分析に Run Analytics を使用する (CRS、rTSS、PMC) ソーシャル共有とマルチスポーツのログ記録には Strava を使用します。それらは互いにうまく補完し合います。

Run Analytics は Garmin ウォッチで動作しますか?

いいえ。Run Analytics は Apple Health 経由で同期します。これには Apple Watch が必要です。ガーミンをお使いの方は、 代わりに、TrainingPeaks または Final Surge を検討してください。

Run Analytics が TrainingPeaks よりもはるかに安いのはなぜですか?

プロテクト18Xは実行専用、マルチスポーツではありません。ランニングだけに集中することで、 バイクのパワーメーター、ランニングダイナミクス、コーチをサポートするための複雑さとインフラストラクチャのコストを回避します。 これにより、PMC + rTSS を 80% 低コストで提供できるようになります。

私がトライアスリートの場合、Run Analytics を使用する必要がありますか?

おそらくメインのアプリではないでしょう。トライアスリートは、次のようなマルチスポーツ プラットフォームから恩恵を受けます。 自転車、ランニング、そしてランニングを追跡する TrainingPeaks。ただし、トライアスリートの中にはRun Analyticsを使用している人もいます。 ランニング固有の分析 (CRS ゾーン) と全体的なトレーニング負荷に対する TrainingPeaks。

Run Analytics には無料利用枠がありますか?

Run Analytics は、7日間の無料トライアルフル機能 (CRS テスト、rTSS、PMC) を備えています。 試用後は月額 3.99 ドルで、長期契約はありません。無料利用枠はありません - アスリートは無料利用枠に値すると信じています 任意の機能ロックのない分析。

Run Analytics を試す準備はできましたか?

CRS ベースのトレーニング ゾーン、自動 rTSS、および手頃な価格の PMC メトリクスを体験してください。 ランナーのために特別に設計されました。
