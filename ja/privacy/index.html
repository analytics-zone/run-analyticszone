Run Analyticsのプライバシーポリシー

最終更新日:2025 年 1 月 10 日 |効果的 日付:2025 年 1 月 10 日

はじめに

Run Analytics (「当社」、「当社の」、または「アプリ」) は、お客様のプライバシーの保護に取り組んでいます。このプライバシーポリシー 当社のモバイル アプリケーション (iOS および Android) がどのように健康データにアクセスし、使用し、保護するかを説明します。 デバイス。

主要なプライバシー原則:Run Analytics はゼロサーバー、ローカルのみ 建築。 Apple HealthKit (iOS) または Health Connect からアクセスされるすべての健康データ (Android) 物理デバイス上にのみ残り、外部サーバーに送信されることはありません。 クラウド サービスまたはサードパーティ。

1. 健康データへのアクセス

Run Analytics は、デバイスのネイティブ健康プラットフォームと統合して、詳細なランニング ワークアウトを提供します 分析:

1.1 iOS - Apple HealthKit の統合

iOS デバイスでは、Run Analytics はApple ヘルスキットランニングワークアウトにアクセスするには データ。以下に対する読み取り専用アクセスを要求します。

  • ワークアウトセッション:時間と期間を指定してエクササイズ セッションを実行する
  • 距離:総走行距離
  • 心拍数:ワークアウト中の心拍数データ
  • アクティブエネルギー:ランニングセッション中に消費されるカロリー
  • 歩数:ケイデンス計算用ステップデータ

Apple HealthKit コンプライアンス:Run Analytics は、Apple HealthKit のすべてのガイドラインに準拠しています。 あなたの健康データはすべて iOS デバイス上で処理され、そこから離れることはありません。 HealthKit を共有することはありません サードパーティ、広告プラットフォーム、またはデータブローカーとのデータ。

1.2 Android - ヘルスコネクトの統合

健康データの種類 許可 目的
エクササイズセッション READ_EXERCISE ヘルスコネクトから実行中のワークアウト セッションを特定してインポートするには
距離記録 READ_DISTANCE ランごとの合計距離、スプリット、ペースの計算などの主要な指標を表示するには
心拍数の記録 READ_HEART_RATE 心拍数グラフを表示するには、ワークアウト中の平均心拍数と最大心拍数を計算します。
速度記録 READ_SPEED ランニングペースとペースゾーンを計算して表示するには
ステップ READ_STEPS ランニングケイデンス（1分あたりのステップ数）を計算するには
消費カロリー READ_TOTAL_CALORIES_BURNED ランニングセッション中のエネルギー消費の包括的な概要を提供するため

Androidの権限:これらの権限は、アプリの最初の起動時に要求されます。あなた これらの権限は、「Android 設定」→「アプリ」→「ヘルスコネクト」→「実行」からいつでも取り消すことができます。 分析。

1.3 健康データの使用方法

すべての健康データが使用されます以下の目的のみに使用します:

  • ワークアウト表示:詳細な指標 (距離、時間、 ペース、心拍数）
  • パフォーマンス分析:ペースゾーン、ケイデンス分析、閾値ペースを計算し、 rTSS (ランニング トレーニング ストレス スコア)
  • 進捗状況の追跡:パフォーマンスの傾向、自己ベスト、トレーニングを表示 要約
  • データのエクスポート:個人使用のためにワークアウト データを CSV 形式にエクスポートできます

1.4 データストレージ

🔒 重要なプライバシーの保証:

すべての健康データは物理デバイス上に独占的に残ります。

  • プロテクト24X:データは iOS コア データと UserDefaults を使用して保存されます (デバイス上のみ)
  • アンドロイド:データは Android Room データベース (オンデバイス SQLite) を使用して保存されます
  • データは外部サーバーにアップロードされません
  • データはインターネット経由で送信されません
  • 健康データのクラウド同期やバックアップはありません
  • 第三者によるあなたの健康データへのアクセスは禁止されています

データがデバイスから送信されるのは次の場合のみです。あなたが明示的に選択しますをエクスポートするには ワークアウトを CSV 形式に変換し、ファイルを自分で共有します。

2. 必要な権限

2.1 iOS 権限

  • ヘルスキットへのアクセス:ワークアウト、距離、心拍数、活動エネルギー、および ステップ
  • 写真ライブラリ (オプション):ワークアウトの概要を画像として保存することを選択した場合のみ

HealthKit の権限は、「iOS 設定」→「プライバシーとセキュリティ」→「健康状態」→「実行」でいつでも管理できます。 分析。

2.2 Android の権限

  • android.permission.health.READ_EXERCISE
  • android.permission.health.READ_DISTANCE
  • android.permission.health.READ_HEART_RATE
  • android.permission.health.READ_SPEED
  • android.permission.health.READ_STEPS
  • android.permission.health.READ_TOTAL_CALORIES_BURNED
  • インターネットアクセス(INTERNET): 静的なアプリ内を表示するためにのみ使用されます コンテンツとサブスクリプション管理へのアクセス (Google Play 請求)。健康データは送信されません。
  • フォアグラウンドサービス(FOREGROUND_SERVICE): 潜在的な未来のために バックグラウンド同期機能 (現在は実装されていません)。

3. 当社が収集しないデータ

Run Analytics は、そうではない以下を収集、保存、または送信します。

  • ❌ 個人識別情報（氏名、メールアドレス、電話番号）
  • ❌ デバイス識別子 (iOS では IDFA、Android では広告 ID)
  • ❌ 位置データまたは GPS 座標
  • ❌ 使用状況分析またはアプリの動作追跡
  • ❌ クラッシュレポートまたは診断データを外部サーバーに送信
  • ❌ サードパーティの SDK または分析サービスを介したデータ

私たちが使用するのはサードパーティの追跡ライブラリはゼロ以下を含む：

  • Google アナリティクス / Firebase アナリティクスなし
  • Facebook SDKなし
  • 広告SDKなし
  • クラッシュ報告サービスなし (Crashlytics、Sentry など)

4. アプリ内購入とサブスクリプション

Run Analytics は、デバイスのネイティブ支払いシステムを通じて管理されるオプションのアプリ内サブスクリプションを提供します。

4.1 iOS - App Store サブスクリプション

iOS でサブスクリプションを購入すると:

  • Apple はすべての支払い処理を App Store を通じて処理します
  • StoreKit を通じてサブスクリプション ステータス (アクティブ/非アクティブ) のみを受け取ります。
  • 当社はあなたの支払い情報 (クレジット カード、請求先住所) にはアクセスできません。
  • サブスクリプションデータはデバイス上にローカルに保存されます

サブスクリプションを管理する:

  • iOS 設定 → あなたの名前 → サブスクリプション → Run Analytics
  • またはアプリ内: [設定] → [サブスクリプションの管理]

4.2 Android - Google Play の請求

Android でサブスクリプションを購入する場合:

  • Google Play がすべての支払い処理を処理します
  • Google Play Billing API を通じてサブスクリプション ステータス (アクティブ/非アクティブ) のみを受け取ります。
  • 当社はあなたの支払い情報 (クレジット カード、請求先住所) にはアクセスできません。
  • サブスクリプションデータはデバイス上にローカルに保存されます

サブスクリプションを管理する:

  • Google Play ストア → アカウント → 定期購入 → Run Analytics
  • またはアプリ内: [設定] → [サブスクリプションの管理]

5. データの保持と削除

5.1 データの保持

  • 健康データはデバイスに保存されます無限に手動で削除するまで
  • ワークアウトデータは、履歴パフォーマンスの追跡と分析を提供するために保持されます。

5.2 データの削除

データはいつでも削除できます。

方法 1: 個々のワークアウトを削除する

  • ワークアウトの詳細画面を開く
  • 削除ボタン（ゴミ箱アイコン）をタップします
  • 削除の確認

方法 2: すべてのアプリデータをクリアする

  • プロテクト24X:アプリを削除して再インストールします (すべてのローカル データが削除されます)
  • アンドロイド:設定→アプリ→Run Analytics→ストレージ→データ消去

方法 3: アプリをアンインストールする

  • Run Analytics をアンインストールすると、すべてのローカル データが自動的に削除されます

方法 4: 健康状態のアクセス許可を取り消す

  • プロテクト24X:設定 → プライバシーとセキュリティ → 健康状態 → Run Analytics → すべてオフにする カテゴリー
  • アンドロイド:設定 → アプリ → ヘルスコネクト → Run Analytics → すべての権限を取り消す

6. データセキュリティ

すべてのデータがデバイス上に残っているにもかかわらず、当社はデータのセキュリティを真剣に考えています。

6.1 セキュリティ対策

  • iOS セキュリティ:iOS Core Data を使用して保存されたすべてのデータは、iOS キーチェーンによって保護され、 デバイスの暗号化。デバイスがロックされている場合、データは保護されます。
  • Androidのセキュリティ:Room Database に保存されているすべてのデータは Android のセキュリティによって保護されています。 組み込みのセキュリティとアプリのサンドボックス。
  • ネットワーク送信なし:健康データがデバイスから離れることはなく、 送信セキュリティのリスク
  • アプリのサンドボックス化:iOS と Android アプリのサンドボックスにより、他のアプリが Run にアクセスできなくなります 分析データ
  • 安全なストレージ:デバイス認証がなければ健康データにアクセスできない (パスコード、Face ID、Touch ID、指紋、顔認証ロック解除)

6.2 あなたの責任

データを保護するには:

  • 強力なパスコード/生体認証を使用してデバイスをロックしたままにします
  • 最新のセキュリティ パッチを適用して OS を常に最新の状態に保ちます
  • プロテクト24X:デバイスを脱獄しないでください
  • アンドロイド:デバイスをルート化しないでください

7. データ共有とサードパーティ

Run Analytics はあなたの健康データを第三者と共有しません。

7.1 データ共有の禁止

  • 私たちはあなたのデータを販売しません
  • あなたのデータを広告主と共有することはありません
  • 当社はあなたのデータを分析会社に提供しません
  • ソーシャルメディアプラットフォームと統合しません

7.2 CSV エクスポート (ユーザーが開始した場合のみ)

データがデバイスから流出する唯一の方法は次の場合です。あなた明示的に:

  1. 「設定」→「生データのエクスポート」に移動します
  2. CSV ファイルを生成する
  3. デバイスの共有メニュー (電子メール、クラウド ストレージ、メッセージング アプリ) を通じて CSV ファイルを共有することを選択します。

これは完全にあなたの制御下にあります。

8. 子供のプライバシー

Run Analytics は、13 歳未満の子供から故意にデータを収集しません。アプリはそうではありません 年齢情報を要求しますが、親は子供の健康追跡の使用を監督する必要があります アプリケーション。

13 歳未満の子供が Run Analytics を使用したと思われる場合は、当社にご連絡ください。 すべてのローカル データがデバイスから確実に削除されるようにします。

9. 国際的なデータ転送

該当なし。すべての健康データはデバイス上に独占的に残るため (iOS または Android) を使用しており、サーバーに送信されることはなく、国際的なデータ転送はありません。

10. お客様の権利 (GDPR、CCPA 準拠)

Run Analytics はサーバー上で個人データを収集しませんが、お客様のデータ プライバシーの権利を尊重します。

10.1 GDPR の権利 (ヨーロッパのユーザー)

  • アクセスする権利:すべてのデータにはアプリ内でいつでもアクセスできます
  • 削除する権利:セクション 5.2 で説明されている方法を使用してデータを削除します。
  • ポータビリティの権利:データをCSV形式にエクスポートします（設定→生データのエクスポート）
  • 処理を制限する権利:ヘルスアクセス許可を取り消して新しいデータアクセスを停止します

10.2 CCPA の権利 (カリフォルニア州ユーザー)

  • 知る権利:このポリシーは、アクセスされるすべてのデータとその使用方法を開示します。
  • 削除する権利:セクション 5.2 で説明されている方法を使用してデータを削除します。
  • 販売をオプトアウトする権利:該当なし (データを販売することはありません)

11. このプライバシーポリシーの変更

当社は、このプライバシー ポリシーを随時更新することがあります。変更を加える場合:

  • このポリシーの上部にある「最終更新日」が変更されます
  • 重要な変更はアプリ内で発表されます
  • 変更後もアプリを継続して使用すると、更新されたポリシーに同意したことになります。

当社がお客様のプライバシーをどのように保護しているかについて常に最新の情報を得るために、このポリシーを定期的に確認することをお勧めします。

12.お問い合わせ

このプライバシー ポリシーまたはお客様のデータに関してご質問、懸念事項、またはリクエストがある場合は、 プライバシー:

  • 電子メール:Analyticszone@onmedic.org
  • ウェブサイト: https://runanalytics.app

応答時間:当社はすべてのプライバシーに関するお問い合わせに 7 営業日以内に回答するよう努めております。

13. 法令遵守

Run Analytics は以下に準拠しています。

  • プロテクト24X:Apple App Store レビュー ガイドライン、Apple HealthKit ガイドライン
  • アンドロイド:Google Play デベロッパー プログラム ポリシー、Android ヘルスコネクト ガイドライン
  • 一般データ保護規則 (GDPR)
  • カリフォルニア州消費者プライバシー法 (CCPA)
  • 児童オンラインプライバシー保護法 (COPPA)

概要

簡単に言うと:

  • ✅私たちがアクセスするもの:Apple HealthKit (iOS) または Health Connect からワークアウト データを実行する (アンドロイド)
  • ✅保存場所:お使いのデバイス上のみ (iOS コア データまたは Android Room データベース)
  • ✅どこへ行くか:どこにもない。デバイスから離れることはありません。
  • ✅誰が見るか:あなただけです。
  • ✅削除方法:いつでもアプリのデータを消去したり、アプリをアンインストールしたりできます。

Run Analytics はプライバシーを第一に設計されています。あなたのランニングデータはあなたのものであり、あなたのデータに残ります。 デバイス。
