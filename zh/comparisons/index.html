为什么跑步需要专业分析

Strava 和 TrainingPeaks 等一般健身应用程序擅长骑自行车和跑步，但跑步 需要不同的指标。临界跑步速度 (CRS)、基于配速的训练区和步幅 多种运动平台未正确支持力学。 Run Analytics 专为 跑步，具有专为田径和越野跑运动员设计的指标。

Run Analytics 与 Strava 对比

Strava 擅长什么

  • 社交功能：俱乐部、细分、荣誉、活动源
  • 多项运动追踪：跑步、骑自行车、跑步、徒步等。
  • 免费等级：为休闲运动员提供丰富的免费功能
  • 庞大的用户群：与全球数百万运动员联系
  • Apple Watch 集成：直接同步锻炼

Run Analytics 有何优势

  • 特定于跑步的指标：CRS、rTSS、专为赛道设计的配速区
  • 训练负荷分析：包括 CTL/ATL/TSB（Strava 没有这个）
  • 自动保护14X：无需手动输入数据，由 CRS +pace 计算得出
  • 步幅力学：DPS、步幅率、步幅指数跟踪
  • 训练区：根据您的生理机能设置 6 个个性化步速区域

结论：Run Analytics 与 Strava

如果出现以下情况，请使用 Strava：您需要社交功能、多项运动跟踪或免费休闲跟踪。 Strava 非常适合记录锻炼和与朋友联系。

如果出现以下情况，请使用 Run Analytics：您非常重视跑步性能并想要基于 CRS 的区域， 自动 rTSS 和训练负荷管理 (CTL/ATL/TSB)。 Strava 不会计算正在运行的 TSS 或 提供 PMC 指标。

两者同时使用：许多跑步者使用 Strava 进行社交分享，使用 Run Analytics 进行社交分享 绩效跟踪。他们相得益彰。

Run Analytics 与 TrainingPeaks 对比

TrainingPeaks 擅长什么

  • 全面的 PMC：行业标准 CTL/ATL/TSB 图表
  • 锻炼库：数千次结构化锻炼
  • 教练整合：专业教练运动员平台
  • 多项运动训练：以铁人三项为重点，涵盖所有三项运动
  • 高级分析：自行车/跑步的功率、心率区域

Run Analytics 有何优势

  • 自动 CRS 测试：内置 CRS 计算器，具有区域生成功能
  • 包括用于运行的 PMC：TrainingPeaks 需要 20 美元/月的 PMC 溢价
  • 简化的界面：Run Analytics 专注于跑步，而不是压倒性的
  • Apple Watch 原生：通过 Apple Health 直接同步（无需 Garmin）
  • 成本更低：3.99 美元/月 vs TrainingPeaks Premium 20 美元/月

结论：Run Analytics 与 TrainingPeaks

如果出现以下情况，请使用 TrainingPeaks：您是一名铁人三项运动员，正在接受多项运动项目的训练，有教练 使用 TrainingPeaks，或者需要结构化的自行车/跑步锻炼。 TrainingPeaks 擅长提供全面的 铁人三项训练。

如果出现以下情况，请使用 Run Analytics：您是跑步者（不是铁人三项运动员）或想要特定于跑步的指标 无需支付 20 美元/月。 Run Analytics 提供 CTL/ATL/TSB 和 rTSS 计算，成本比 TrainingPeaks 高级版。

主要区别：TrainingPeaks 是一项具有教练功能的多项运动；运行 分析仅在本机 CRS 支持和经济实惠的 PMC 访问的情况下运行。

Run Analytics 与 Final Surge

Final Surge 的优点是什么

  • 教练平台：专为教练与运动员的关系而设计
  • TSS 支持：运行 TSS 计算可用
  • 多项运动：跑步、跑步、骑自行车、力量
  • 锻炼计划：基于日历的培训计划
  • 通讯工具：应用内教练消息传递

Run Analytics 有何优势

  • 本机 CRS 测试：内置计算器，无需手动输入
  • 自动保护14X：根据 Apple Watch 数据计算，无日志记录
  • 个人运动员关注点：专为自学跑步者设计
  • Apple Watch 集成：无缝健康应用程序同步
  • 专业跑步：不被多项运动功能冲淡

结论：Run Analytics 与 Final Surge

如果出现以下情况，请使用 Final Surge：您有一位使用 Final Surge 的教练，或者您正在指导运动员。 Final Surge 首先是一个教练平台，其次是运动员应用程序。

如果出现以下情况，请使用 Run Analytics：您是自我训练者并且需要自动化分析。保护18X 需要零手动记录——所有内容都会自动从 Apple Watch 同步。

主要区别：Final Surge 以教练为中心； Run Analytics 是 以运动员为中心，以自动化为重点。

Run Analytics 有何独特之处

1. 一流的 CRS 支持

Run Analytics 是唯一的应用程序使用本机 CRS 测试计算器。输入您的 5K 和 3K次，即刻得到：

  • CRS 配速（例如 1:49/100m）
  • 6个个性化训练区
  • 所有锻炼的自动 rTSS 计算
  • 基于区域的锻炼分析

竞争对手：需要手动区域设置或不支持运行区域 根本不。

2. 运行时自动rTSS

大多数应用程序需要手动输入 TSS，或者根本不计算运行 TSS。保护18X：

  • 自动计算每次 Apple Watch 锻炼的 rTSS
  • 使用 CRS + 锻炼速度来确定强度系数
  • 无需手动记录 - 设置 CRS 一次，就不用管它了

斯特拉瓦：不计算运行TSS。训练高峰：需要 20 美元/月的保费。最终浪涌：需要手动输入。

3.经济实惠的PMC访问

绩效管理图表（CTL/ATL/TSB）是对于训练负荷至关重要 管理，但在其他平台上价格昂贵：

  • 保护18X：包含费用为 3.99 美元/月
  • 训练高峰：需要 20 美元/月保费（240 美元/年）
  • 斯特拉瓦：不以任何价格提供
  • 最终浪涌：保费 10 美元/月（120 美元/年）

Run Analytics 提供 CTL/ATL/TSB成本降低 80%比 训练高峰。

4.Apple Watch本机

Run Analytics 直接与 Apple Health 同步 — 无需 Garmin 手表：

  • 适用于任何 Apple Watch（系列 2+）
  • 从健康应用程序自动导入锻炼数据
  • 公里配速、步数、跑步效率
  • 无需额外硬件

训练高峰：需要 Garmin/Wahoo 设备（200-800 美元）。斯特拉瓦：可与 Apple Watch 配合使用，但缺乏运行分析功能。

5.专注于跑步

多运动应用程序尝试做所有事情，但通常表现不佳。 Run Analytics 是建成 专为跑步而设：

  • 围绕赛道训练工作流程设计的界面
  • 与跑步者相关的指标（CRS、rTSS、步幅力学）
  • 自行车/跑步/远足跟踪不会造成功能膨胀
  • 更新侧重于运行改进

常见问题解答

我可以使用 Run Analytics 和 Strava/TrainingPeaks 吗？

是的，许多跑步者两者都使用。使用 Run Analytics 进行性能分析（CRS、rTSS、PMC） Strava 用于社交共享和多项运动记录。他们相得益彰。

Run Analytics 可以与 Garmin 手表配合使用吗？

不。Run Analytics 通过 Apple Health 同步，这需要 Apple Watch。如果您使用 Garmin， 请考虑 TrainingPeaks 或 Final Surge。

为什么 Run Analytics 比 TrainingPeaks 便宜这么多？

Run Analytics 是仅运行，而不是多项运动。通过专注于跑步，我们 避免支持自行车功率计、跑步动态、教练的复杂性和基础设施成本 平台等。这使我们能够以降低 80% 的成本提供 PMC + rTSS。

如果我是一名铁人三项运动员，我应该使用 Run Analytics 吗？

可能不是您的主要应用程序。铁人三项运动员受益于多种运动平台，例如 TrainingPeaks 可以追踪自行车、跑步和跑步。然而，一些铁人三项运动员使用 Run Analytics 特定于运行的分析（CRS 区域）和整体训练负载的 TrainingPeaks。
