Patakaran sa Privacy para sa Run Analytics

Huling Na-update:Enero 10, 2025 |Epektibo Petsa:Enero 10, 2025

Panimula

Ang Run Analytics ("kami," "aming," o "ang app") ay nakatuon sa pagprotekta sa iyong privacy. Patakaran sa Privacy na ito ipinapaliwanag kung paano ina-access, ginagamit, at pinoprotektahan ng aming mga mobile application (iOS at Android) ang data ng kalusugan mula sa iyong aparato.

Pangunahing Prinsipyo sa Privacy:Gumagana ang Run Analytics sa isangzero-server, local-only arkitektura. Lahat ng data ng kalusugan na na-access mula sa Apple HealthKit (iOS) o Health Connect (Android) ay nananatiling eksklusibo sa iyong pisikal na device at hindi kailanman ipinapadala sa mga panlabas na server, mga serbisyo sa cloud, o mga ikatlong partido.

1. Access sa Data ng Kalusugan

Sumasama ang Run Analytics sa native na platform ng kalusugan ng iyong device upang magbigay ng detalyadong running workout pagsusuri:

1.1 iOS - Pagsasama ng Apple HealthKit

Sa iOS device, ang Run Analytics ay sumasama saApple HealthKitpara ma-access ang running workout datos. Humihiling kami ng read-only na access sa:

  • Mga Sesyon ng Pag-eehersisyo:Pagpapatakbo ng mga sesyon ng ehersisyo na may oras at tagal
  • Distansya:Kabuuang mga distansya sa pagtakbo
  • Rate ng Puso:Data ng rate ng puso habang nag-eehersisyo
  • Aktibong Enerhiya:Nasusunog ang mga calorie habang tumatakbo ang mga session
  • Bilang ng Hakbang:Data ng hakbang para sa pagkalkula ng indayog

Pagsunod sa Apple HealthKit:Ang Run Analytics ay sumusunod sa lahat ng mga alituntunin ng Apple HealthKit. Ang iyong data ng kalusugan ay ganap na pinoproseso sa iyong iOS device at hindi ito iiwan. Hindi kami kailanman nagbabahagi ng HealthKit data sa mga third party, advertising platform, o data broker.

1.2 Android - Pagsasama ng Health Connect

Mga Pahintulot sa Android:Ang mga pahintulot na ito ay hinihiling sa unang paglulunsad ng app. Ikaw maaaring bawiin ang mga pahintulot na ito anumang oras sa pamamagitan ng Mga Setting ng Android → Apps → Health Connect → Run Analytics.

1.3 Paano Namin Ginagamit ang Data ng Kalusugan

Lahat ng data ng kalusugan ay ginagamiteksklusibo para sa mga sumusunod na layunin:

  • Pagpapakita ng Pagsasanay:Ipakita ang iyong mga tumatakbong session na may mga detalyadong sukatan (distansya, oras, bilis, tibok ng puso)
  • Analytics ng Pagganap:Kalkulahin ang mga pace zone, cadence analysis, Threshold Pace, at rTSS (Running Training Stress Score)
  • Pagsubaybay sa Pag-unlad:Ipakita ang mga trend ng pagganap, personal na pinakamahusay, at pag-eehersisyo mga buod
  • Pag-export ng Data:Nagbibigay-daan sa iyong i-export ang iyong data sa pag-eehersisyo sa CSV na format para sa personal na paggamit

1.4 Imbakan ng Data

🔒 KRITIKAL NA PRIVACY GUARANTEE:

Ang lahat ng data ng kalusugan ay nananatiling eksklusibo sa iyong pisikal na device.

  • iOS:Iniimbak ang data gamit ang iOS Core Data at UserDefaults (on-device lang)
  • Android:Iniimbak ang data gamit ang Android Room Database (on-device SQLite)
  • WALANG data ang na-upload sa mga panlabas na server
  • WALANG data ang ipinadala sa internet
  • WALANG cloud synchronization o backup ng data ng kalusugan
  • WALANG third-party na access sa iyong data ng kalusugan

Ang tanging oras na umalis ang data sa iyong device ay kung kailanTAHASANG pipiliin MOupang i-export ang iyong mag-ehersisyo sa CSV na format at ibahagi ang file sa iyong sarili.

2. Kinakailangan ang mga Pahintulot

2.1 iOS Mga Pahintulot

  • Access sa HealthKit:Read access sa Workouts, Distansya, Heart Rate, Active Energy, at Mga hakbang
  • Photo Library (Opsyonal):Kung pipiliin mo lang na i-save ang mga buod ng pag-eehersisyo bilang mga larawan

Maaari mong pamahalaan ang mga pahintulot sa HealthKit anumang oras sa Mga Setting ng iOS → Privacy at Seguridad → Health → Run Analytics.

2.2 Mga Pahintulot sa Android

  • android.permission.health.READ_EXERCISE
  • android.permission.health.READ_DISTANCE
  • android.permission.health.READ_HEART_RATE
  • android.permission.health.READ_SPEED
  • android.permission.health.READ_STEPS
  • android.permission.health.READ_TOTAL_CALORIES_BURNED
  • Access sa Internet(INTERNET): Ginagamit lang para sa pagpapakita ng static na in-app nilalaman at pag-access sa pamamahala ng subscription (Pagsingil sa Google Play). Walang data ng kalusugan na ipinadala.
  • Serbisyo sa harapan(FOREGROUND_SERVICE): Para sa potensyal na hinaharap mga tampok sa pag-sync sa background (kasalukuyang hindi ipinapatupad).

3. Data na HINDI Namin Kinokolekta

Ginagawa ng Run AnalyticsHINDImangolekta, mag-imbak, o magpadala:

  • ❌ Personal na impormasyon ng pagkakakilanlan (pangalan, email, numero ng telepono)
  • ❌ Mga identifier ng device (IDFA sa iOS, advertising ID sa Android)
  • ❌ Data ng lokasyon o mga coordinate ng GPS
  • ❌ Analytics ng paggamit o pagsubaybay sa gawi ng app
  • ❌ Mga ulat ng pag-crash o diagnostic data sa mga external na server
  • ❌ Anumang data sa pamamagitan ng mga third-party na SDK o mga serbisyo ng analytics

Ginagamit naminzero third-party tracking librarykasama ang:

  • Walang Google Analytics / Firebase Analytics
  • Walang Facebook SDK
  • Walang mga SDK sa advertising
  • Walang mga serbisyo sa pag-uulat ng pag-crash (Crashlytics, Sentry, atbp.)

4. Mga In-App na Pagbili at Subscription

Nag-aalok ang Run Analytics ng mga opsyonal na in-app na subscription na pinamamahalaan sa pamamagitan ng native na sistema ng pagbabayad ng iyong device:

4.1 iOS - App Store Mga Subscription

Kapag bumili ka ng subscription sa iOS:

  • Pinangangasiwaan ng Apple ang lahat ng pagproseso ng pagbabayad sa pamamagitan ng App Store
  • Natatanggap lang namin ang status ng subscription (aktibo/hindi aktibo) sa pamamagitan ng StoreKit
  • WALA kaming access sa iyong impormasyon sa pagbabayad (credit card, billing address)
  • Lokal na iniimbak ang data ng subscription sa iyong device

Pamahalaan ang mga subscription:

  • Mga Setting ng iOS → Iyong Pangalan → Mga Subscription → Run Analytics
  • O sa loob ng app: Mga Setting → Pamahalaan ang Subscription

4.2 Android - Pagsingil sa Google Play

Kapag bumili ka ng subscription sa Android:

  • Pinangangasiwaan ng Google Play ang lahat ng pagpoproseso ng pagbabayad
  • Natatanggap lang namin ang status ng subscription (aktibo/hindi aktibo) sa pamamagitan ng Google Play Billing API
  • WALA kaming access sa iyong impormasyon sa pagbabayad (credit card, billing address)
  • Lokal na iniimbak ang data ng subscription sa iyong device

Pamahalaan ang mga subscription:

  • Google Play Store → Account → Mga Subscription → Run Analytics
  • O sa loob ng app: Mga Setting → Pamahalaan ang Subscription

5. Pagpapanatili at Pagtanggal ng Data

5.1 Pagpapanatili ng Data

  • Ang data ng kalusugan ay nakaimbak sa iyong devicewalang katiyakanhanggang sa manu-mano mong tanggalin ito
  • Ang data ng pag-eehersisyo ay pinapanatili upang magbigay ng makasaysayang pagsubaybay sa pagganap at analytics

5.2 Pagtanggal ng Data

Maaari mong tanggalin ang iyong data anumang oras:

Paraan 1: Tanggalin ang Mga Indibidwal na Pag-eehersisyo

  • Buksan ang screen ng detalye ng pag-eehersisyo
  • I-tap ang delete button (icon ng basura)
  • Kumpirmahin ang pagtanggal

Paraan 2: I-clear ang Lahat ng Data ng App

  • iOS:Tanggalin at muling i-install ang app (aalisin ang lahat ng lokal na data)
  • Android:Mga Setting → Apps → Run Analytics → Storage → I-clear ang data

Paraan 3: I-uninstall ang App

  • Awtomatikong tinatanggal ng pag-uninstall ng Run Analytics ang lahat ng lokal na data

Paraan 4: Bawiin ang Mga Pahintulot sa Kalusugan

  • iOS:Mga Setting → Privacy at Seguridad → Kalusugan → Run Analytics → I-off ang Lahat Mga kategorya
  • Android:Mga Setting → Apps → Health Connect → Run Analytics → Bawiin ang lahat ng pahintulot

6. Seguridad ng Data

Sineseryoso namin ang seguridad ng data, kahit na nananatili ang lahat ng data sa iyong device:

6.1 Mga Panukala sa Seguridad

  • iOS Seguridad:Ang lahat ng data na nakaimbak gamit ang iOS Core Data ay protektado ng iOS Keychain at pag-encrypt ng device. Pinoprotektahan ang data kapag naka-lock ang device.
  • Android Security:Ang lahat ng data na nakaimbak sa Room Database ay protektado ng Android built-in na seguridad at app sandbox.
  • Walang Network Transmission:Ang data ng kalusugan ay hindi kailanman umaalis sa iyong device, inaalis mga panganib sa seguridad ng paghahatid
  • App Sandboxing:Pinipigilan ng iOS at mga sandbox ng Android app ang iba pang app na ma-access ang Run Data ng Analytics
  • Ligtas na Imbakan:Hindi maa-access ang data ng kalusugan nang walang pag-authenticate ng device (passcode, Face ID, Touch ID, fingerprint, face unlock)

6.2 Ang Iyong Pananagutan

Para protektahan ang iyong data:

  • Panatilihing naka-lock ang iyong device gamit ang isang malakas na passcode/biometric
  • Panatilihing updated ang iyong OS gamit ang mga pinakabagong patch ng seguridad
  • iOS:Huwag i-jailbreak ang iyong device
  • Android:Huwag i-root ang iyong device

7. Pagbabahagi ng Data at Mga Third Party

HINDI ibinabahagi ng Run Analytics ang iyong data sa kalusugan sa anumang mga ikatlong partido.

7.1 Walang Pagbabahagi ng Data

  • Hindi namin ibinebenta ang iyong data
  • Hindi namin ibinabahagi ang iyong data sa mga advertiser
  • Hindi namin ibinibigay ang iyong data sa mga kumpanya ng analytics
  • Hindi kami sumasama sa mga platform ng social media

7.2 CSV Export (User-Initiated Only)

Ang tanging paraan na umalis ang data sa iyong device ay kung kailanIKAWtahasan:

  1. Mag-navigate sa Mga Setting → Pag-export ng Raw Data
  2. Bumuo ng isang CSV file
  3. Piliing ibahagi ang CSV file sa pamamagitan ng share menu ng iyong device (email, cloud storage, messaging apps)

Ito ay ganap na nasa ilalim ng iyong kontrol.

8. Privacy ng mga Bata

Ang Run Analytics ay hindi sadyang nangongolekta ng data mula sa mga batang wala pang 13 taong gulang. Ang app ay hindi humiling ng impormasyon sa edad, ngunit dapat pangasiwaan ng mga magulang ang paggamit ng kanilang mga anak ng pagsubaybay sa kalusugan mga aplikasyon.

Kung naniniwala ka na ang isang batang wala pang 13 taong gulang ay gumamit ng Run Analytics, mangyaring makipag-ugnayan sa amin, at kami ay tutulong pagtiyak na ang lahat ng lokal na data ay tatanggalin mula sa device.

9. International Data Transfers

Hindi Naaangkop.Dahil ang lahat ng data ng kalusugan ay nananatiling eksklusibo sa iyong device (iOS o Android) at hindi kailanman ipinapadala sa mga server, walang mga internasyonal na paglilipat ng data.

10. Ang Iyong Mga Karapatan (GDPR, Pagsunod sa CCPA)

Bagama't hindi nangongolekta ang Run Analytics ng personal na data sa mga server, iginagalang namin ang iyong mga karapatan sa privacy ng data:

10.1 Mga Karapatan ng GDPR (Mga European User)

  • Karapatan sa Pag-access:Ang lahat ng iyong data ay maa-access sa loob ng app anumang oras
  • Karapatan sa Pagtanggal:Tanggalin ang data gamit ang mga pamamaraang inilarawan sa Seksyon 5.2
  • Karapatan sa Portability:I-export ang iyong data sa CSV na format (Mga Setting → Raw Data Export)
  • Karapatan na Paghigpitan ang Pagproseso:Bawiin ang mga pahintulot sa kalusugan upang ihinto ang bagong pag-access sa data

10.2 Mga Karapatan ng CCPA (Mga User ng California)

  • Karapatang Malaman:Ibinunyag ng patakarang ito ang lahat ng data na na-access at kung paano ito ginagamit
  • Karapatang Magtanggal:Tanggalin ang data gamit ang mga pamamaraang inilarawan sa Seksyon 5.2
  • Karapatang Mag-opt-Out sa Pagbebenta:Hindi naaangkop (hindi kami nagbebenta ng data)

11. Mga Pagbabago sa Patakaran sa Privacy na Ito

Maaari naming i-update ang Patakaran sa Privacy na ito paminsan-minsan. Kapag gumawa kami ng mga pagbabago:

  • Ang petsa ng "Huling Na-update" sa itaas ng patakarang ito ay babaguhin
  • Ang mga makabuluhang pagbabago ay iaanunsyo sa loob ng app
  • Ang patuloy na paggamit ng app pagkatapos ng mga pagbabago ay bumubuo ng pagtanggap sa na-update na patakaran

Inirerekomenda naming suriin ang patakarang ito sa pana-panahon upang manatiling may kaalaman tungkol sa kung paano namin pinoprotektahan ang iyong privacy.
